- 每月法定工時與診所工時上限。

- 主管班、行政班及其他特殊班別。

- 資淺助理可跟診，但需要指定資深助理同班或協助。
- 後續員工異動、技能變動及規則更新。
- 產生可人工調整、能說明違規原因的月排班表。

- `原始能力表`：保留來源表的值供查核。

來源符號：

- `◎`：熟練。
- `Ø`：尚未熟練。
- `△`：需加強。
- `※`：學習中。
- 空白：未評分。

摘要的初步轉換規則：

- 已評分項目全部為 `◎`：熟練。
- `Ø` 為 1 至 3 項，且沒有 `△`、`※` 或缺評：可支援。
- `Ø` 超過 3 項，或出現 `△`：需加強。
- 出現 `※`：學習中。
- 應評項目有空白：未評分。

這是依原表註記產生的「排班用初步摘要」，之後仍需由診所確認每位醫師真正的最低技能要求。

尚需使用者或診所提供：

請另一台 Codex 先列出差異，不要直接合併或覆寫：

- 員工主鍵：`員工編號`。
- 技能主鍵：`員工編號 + 工作區塊 + 分類 + 技能項目`。

- 班別主鍵：建議使用穩定的 `班別代碼`，不要只用顯示名稱。
- 使用者明確確認的資料優先於推導結果。

- 原始評分符號必須保留；摘要狀態可以重新計算。
- 空白、未評分、不可排是三種不同狀態。
- 不確定或互相衝突的資料放入「待確認」，不要自行選一邊。
