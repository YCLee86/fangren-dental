一、文章的收尾區塊（data-cta）

為什麼要有：讀完兩千字之後，畫面上沒有任何一句話告訴人下一步該做什麼。
免責聲明那一句「請由醫師評估」正好是個開口，但它後面接的是上下篇。

⚠ 位置刻意放在 </main> **外面**，和「延伸閱讀」同一個理由：
  內容雜湊涵蓋 <main>，放進去的話六篇文章的「最後更新」會一起跳成今天、
  排序跟著亂掉（CLAUDE.md 第五節那個陷阱）。
  順序因此是：內文 → 上下篇 → 收尾區塊 → 延伸閱讀。
  「先讓想找人的人找到人，再給還想讀的人更多文章」，這個順序是對的。

⚠ 顏色一顆都沒有新增：整塊吃該篇自己的 --accent／--accent-deep
  （寫在 <body data-spec="…"> 上，本來就存在）。所以牙周那篇是青綠、
  兒牙那篇是焦糖，自動跟著走。

⚠ **沒有重抄看診時間。** CLAUDE.md 的規矩是「資料不重抄」——
  六篇各放一份時間表，遲早會有一份跟首頁不一樣而且沒有人發現。
  這裡只放一個連結指回首頁那張門診表（../../#clinic）。

⚠ 文案守 COPY.md 的紅線：不寫「問到飽」「來這裡問到懂」「不做也沒關係」。
  「來一趟才有辦法一起決定」刻意回收 HERO 收尾句的「一起想辦法」。

當時放在牙周那篇上的文案（示範用，其他五篇要各自換醫師與科別）：

    牙周這一科，在芳仁是李侑津醫師看的
    牙周的狀況要靠探測與 X 光才判斷得出來，這篇文章只能幫你知道該問什麼。
    要不要處理、怎麼處理，來一趟才有辦法一起決定。
    〔打電話 (05)5339-369〕〔LINE 詢問〕
    看診時間與各科門診表 →

⚠ 真要做的話，這段 HTML **應該由 tools/build.mjs 產生**（六篇共用一份模板，
  醫師與科別從 post-meta 的 tag 對回首頁的 #doctors），不是六篇各手寫一份。
  CSS 則併進 assets/style.css。

三、觸控目標（data-hit / data-hit2）

文章頁的選單只有 23.1px 高 —— 比首頁的 34.3 還小，連 WCAG 2.5.8 的 24 都差一點。
做法同首頁：用看不見的 ::after 撐命中區，不加內距、版面一個像素不動。
⚠ ::before 是那圈玻璃框（2026-08-12 補上線的那一版），所以只能用 ::after。

    html[data-hit="on"] .site-nav a::after { content:''; position:absolute; inset:-11px -4px; }

頁尾（data-hit2）：地址與電話量到 27.4px，而兩行之間只有 5.6px（.35rem），
::after 外擴 8.3px 就會疊到隔壁那一行 —— 所以這一批只能把元素自己長高
（padding-block: 8.5px，順便把 margin 收掉，命中區本來就該連續）。
⚠ 取 8.5 不是 8.3：27.4 是量出來的，字型載入前後會差零點幾。

四、麵包屑那一列拆成兩行（data-crumb）

⚠ **這一項就是第一批留著沒解的那一件。** 麵包屑維持 23.7px，::after 外擴與
  inline-block 都試過、量出來還是 23.7 —— 因為那一列**四個東西擠在同一行**
  （首頁 › 科別藥丸　日期　瀏覽數），命中區往上下撐會直接疊到鄰居。
  當時的結論是「真要解得把那一列改成兩行，那是版面決定」。這一項就是那個版面決定。

做法：日期與瀏覽數包在一個 .crumb-meta 裡，**平常是 display: contents**
（這一層在版面上不存在，兩者仍是 .crumbs 的直接 flex 項目，關掉時和現況
一個像素都不差），打開才變成 flex-basis: 100% 的項目，一起落到第二行。
第一行剩下「首頁 › 牙周照護」，這時 <a> 才有上下的空間可以長到 44。

⚠ **不要只給 <time> 寫 flex-basis: 100%** —— 第一版那樣做，瀏覽數被擠到
  第三行，量出來 107.3px 而不是預期的 76。flex-basis: 100% 的項目會獨佔一整列。
⚠ 用 flex-basis 而不是插一個看不見的換行元素：這一列本來就是 flex-wrap: wrap，
  有一個項目要求 100%，它前面就自動斷行。
⚠ 順便把「首頁」加上底線。理由同 2026-08-09 頁尾地址那一輪：手機沒有 hover，
  只靠 :hover 才表態的連結，對多數訪客等於從來不宣告自己是連結。
⚠ 代價：標題往下移一行的高度（約 33px）。

五、手機行動條（data-bar）與頁尾的 LINE（data-footline）

兩項都是「和首頁那一頁同一份」，定案的話兩邊要共用同一段 CSS。

行動條：固定在畫面底、兩格（打電話／LINE）、墨玻璃 rgba(25,22,20,.88) ＋ blur(14px)、
每格 min-height 56px、body 補 padding-bottom 讓內容不被蓋住、吃 safe-area-inset-bottom。
⚠ 首頁那一輪十九項裡，**手機行動條是沒選上的七項之一**（/history/cta-mobile.html）。
  文章頁這一份如果要重啟，要先確認那個決定有沒有改變。

頁尾的 LINE：全站唯一提到 LINE 的地方是 JSON-LD 的 sameAs，畫面上一個連結都沒有。
⚠ 顏色寫死 #3f654a 不用 var(--accent) —— 文章頁的 --accent 是該篇的科別色，
  LINE 這種全站性的東西不該跟著文章變色。
⚠ 首頁那一輪「頁尾補上 LINE」同樣**沒有選上**。
