起因

使用者：「目前網站上的呈現只有付費停車場　保留原來網站的樣子　我另外加一個標籤是鄰近停車格　按下去再顯示這些位置　先做成預覽給我看」。

格子的來源是 2026-09 那一輪的現地清查（drafts/door-notice/parking-survey.json， 共 19 格 ＋ 文化路・平和街口以西 5 格示意）。

定案

標籤　　　　「位置與周邊停車」旁邊，同一列
　　　　　　幾何整組照抄它左邊那顆 h3（.88rem、上下內距那條 calc、圓角 12px）
　　　　　　⚠ 兩顆藥丸並排，高度不可以各算各的 —— 站上那顆在 ≥721px 乘了
　　　　　　　 --type-scale，這裡也要乘，不然電腦版一顆 38.25、一顆 32.2
夜間沒點亮　套色 20% 的淡色塊（#384050）＋ #90abe1 的字（實測 4.51）
格子　　　　實心路牌藍 ＋ 最細密的虛線框（dasharray 2 1.6、粗 1.2）
虛線的顏色　#282b31 ＝ 夜間模式的卡色，白天夜間釘死成同一支
透感　　　　白天 fill-opacity .55、夜間 .72
號碼　　　　不寫
按下去　　　三塊停車場熄滅、街名一起淡下去；點停車場則格子收起來（兩種模式互斥）
未清查那排　畫出來（class .bay-est）
永樂街　　　被壓到時**移位不是消失**：往上 191、退而往下 154、真的沒地方才藏起來

量出來的

・標籤沒按下去時，地圖與改動前**逐位元組相同**
  （430／393／390／375／360／320／834／1440，DPR 3，白天夜間都驗過）——
  唯一的差是永樂街那一條路名（177 個元素逐項比對，只有那個 text 與它三個 tspan）
・上線之後整頁 69 項版面量測對改動前 **0 項有差**（六個寬度）
・一格在手機（390）上畫出來 8.2×15.0px，1 個 viewBox 單位 ＝ 0.748px
・⚠ 文化路・平和街口以西那 5 格，**手機上只看得到 1 格** ——
  站上的地圖在手機是 preserveAspectRatio slice、左右各裁 65 個單位，
  而那一排落在 x 4~84。電腦與 iPad 五格都看得到。
  **格子的位置是量出來的，不要為了讓它出現在手機上把它往右挪。**
・⚠ 號碼若打開，永安路東側那一排有 **9 個數字**被同一條裁切線切掉 ——
  那是「不寫號碼」的依據，不是憑感覺。
・⚠ 已知取捨：夜間**點亮**那一態白字對 #7a96ca 只有 2.98 ——
  站上夜間的填色藥丸本來就是這一級（--accent 在夜間沒有被覆寫，兒牙 2.54）。

踩過、下次還會踩的

⚠⚠⚠ **使用者說「定案」的時候，定的是他螢幕上那一格，不是產生器裡的預設值。**
　　　收尺之前要先跟他手上那張截圖逐格對一次。（這一輪錯了一次，他補傳截圖才更正。）

⚠⚠⚠ **用 String.replace 往產生器裡插一段程式，錨點要連縮排一起寫死。**
　　　錨點寫「兩個空白 ＋ chips.forEach(...)」，先命中了**縮排四格、在 paint() 裡面
　　　的那一個**，整塊就靜靜地被塞進 paint()：measure() 讀不到那些變數、
　　　而且每按一次標籤就多掛一組 MutationObserver。
　　　→ 產生器因此多一道守門（那支 inline script 要編得過 ＋ 幾支函式只准在最外層各一次）。

⚠⚠⚠ **自己會動到某個 class、又用 MutationObserver 盯著它，就會無限遞迴。**
　　　classList.remove() 就算那個 class 本來不在，也會寫一次 class 屬性、再觸發一次觀察者。
　　　症狀是**整頁卡死在載入中，而且主控台一個錯都沒有**。

⚠⚠⚠ **量一個掛著 transition 的東西的「原位」要用 getBBox() 不是 getBoundingClientRect()。**
　　　後者會量到「動到一半」的位置，下一次判斷就踩在錯的基準上。
　　　同一族：量藥丸的顏色也要等 .15s 的 transition 跑完（不然背景回一串 oklab(...)、
　　　字色還是舊的，**看起來像規則寫錯**）。

⚠⚠ **placeYongle() 要排在 paintLots() 的最後。** 它量的是 .dots.on／.rlab.on 的實際外框，
　　排在那兩行 toggle 之前的話量到的是上一次的狀態 —— **開頁那一次就會停在原位**。

⚠⚠ **驗「路名有沒有被蓋到」要一路往上看祖先的 opacity。** 那幾組點狀路線與牌子是靠
　　**父層**藏起來的，只問元素自己會把看不見的東西全部算進來（誤報八項）。

⚠⚠ **「路名被格子蓋到幾條」要等過場跑完再量**（讓開是 .18s 的 transition，
　　按下去的當下量到的還是舊位置，會誤報兩條）—— 那是量測的假警報不是版面的 bug。

⚠⚠ **那四條 ?o= 的規則和「白天／夜間」那兩條同權重、靠順序決勝**，
　　所以預設**不可以掛 data-pv-o** —— 掛了就永遠贏過那兩條、白天夜間會變成同一個值，
　　**而且畫面看起來完全正常**。

⚠⚠ **往上要讓開的不只那條點狀路線，還有診所圖釘與它那片影子**
　　（.cm-sh 量到 x266~351、y228~245，正好伸進永樂街那一欄 x324~354）——
　　只比路線的話會讓到影子上。116 不夠，191 才夠。

⚠ **實心的透感要用 fill-opacity 不是 opacity**（後者會連框線一起淡掉）。
⚠ **路名讓開要用 CSS 的 transform 不要改 x／y** —— 標籤要能原封不動退回去。
　 transition 要把 opacity 一起寫回來（站上那條 .lbl 本來就有，只寫 transform 會把它蓋掉）。
⚠ **模板字串的 CSS 註解裡不能有反引號** —— 這一站第八次。
