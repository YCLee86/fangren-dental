## 一、動筆之前已經被鎖死的四件

### 1. ⚠⚠ 牆的顏色先算再構圖：這一科只能在**冷光**裡畫

帶子用相乘上色，補償色 = ((套色 − 0.18×墨) ÷ 0.82) × 255 ÷ 牆的該通道。
矯正套色 `#4478b5` 算出來的分子是 **R 74 / G 137 / B 212** ——
也就是**頂 17% 那面牆的藍通道要 ≥ 212**（R ≥ 74、G ≥ 137），帶子才追得上
站上那顆藍標籤。

| 牆 | B | 過不過 |
| --- | --- | --- |
| 冷白牆、白色天花、螢幕／燈箱的溢光 | 230~250 | ✅ |
| 淺藍天 | ~232 | ✅ |
| 米黃牆、木頭色、陶土色 | 170~195 | ❌ 帶子只能往深階漂 |
| 夜景 | — | ❌ |

⚠ 這一格和兒牙**方向相反**（兒牙卡在紅通道 R ≥ 228，只能室內暖光；
矯正卡在藍通道，暖色牆一開始就出局）。**這是七科裡唯一天生要冷光的一科。**
深階 `#244369` 的下限只有 B ≥ 119，寬鬆很多 —— 落套色還是落深階，
等圖出來照兒牙那次做成 LINE 模擬讓使用者挑（紙色字：套色 3.61／深階 7.97；
純白字配套色 4.57。冷色底照判準用紙色）。

### 2. 不能和站上這五張撞

| 已上線 | 它的語彙 |
| --- | --- |
| 一般牙科（分享卡） | 白天巷弄街景、三組人各做各的事 |
| 牙周治療（分享卡） | 診間、醫師持水槍、擬人牙齒＋細菌四散（動） |
| 顯微根管（分享卡） | 診間、醫師坐椅子＋顯微鏡＋大放大圈（靜的一瞬） |
| 兒童牙科（分享卡） | 診間、醫師單膝蹲下、孩子坐診療椅、媽媽站右邊 |
| 〈牙齒矯正〉文章 HERO（會出現在同一頁的文章卡上） | 三格：街上的朋友／餐廳／臥室的牙套盒 |

→ **不畫擬人牙齒**（第三張就是同一個模子）、**不畫診療椅上的治療**
（兒牙那張已經是）、**不畫餐廳／臥室／街上戴牙套的生活片段**（同一頁下面就有那張卡）、
**醫師不坐醫師椅**（顯微根管那張是坐姿）。

### 3. 這一頁的讀者不需要被安撫

七科裡唯一一頁（COPY.md 第九之十六節）：他做過功課、在社群裡看過裝置與拔不拔牙，
缺的是**針對他自己那一口牙的判斷**。所以圖上要有的是「**兩個人一起看同一件東西**」，
不是安慰、不是歡迎、不是求救。

### 4. 圖上不准出現的（除了第十一節那九條）

- ⚠⚠ **任何時間暗示**：日曆、月份、進度條、before/after 兩格。
  療程長度與回診間隔**還沒問到診所**，整頁刻意一個數字都沒有（`ask`）。
- ⚠⚠ **任何比較**：畫壞的牙、別家的成果、對照組。頁面上「排整齊只是一半」
  之所以能寫，正是因為它沒有提到任何人。
- 病人不要畫成青少年 —— 三個現場裡使用者指名看重的是「**年紀不小了，
  現在弄還來得及嗎**」，而學生矯正是最一般的想像（他說那一類比例要降）。
  建議 **35~55 歲**。

## 二、三個梗（提案中，2026-08-24）

那一頁的軸：`stance` = **「排整齊只是一半 —— 咬得不對，拆掉之後很容易又跑回去。」**
`close` = 「查到的不妨帶來問問，好處壞處應該都要弄清楚。」

### Ⓐ 一起看片（插畫師推薦）

診間旁的看片角落。醫師站著，手指點在一片**亮著的側顱 X 光／口內掃描的螢幕**上；
病人（三十幾~五十歲）坐在旁邊的圓凳前傾看，**手上還捏著自己查來的那幾張紙／手機**。
右後方遠一點，一位助理正把一副上下顎模型放上架子（各做各的事 ＝「活潑」）。

- **對到**：［拔不拔　拍照、照 X 光看過，才知道要不要］、［骨頭］、close 的「查到的不妨帶來問問」。
- **視覺中心**：發亮的片子（畫面高的 ~45%），是整張圖唯一亮的東西。
- **250px**：兩個人的身體都朝向同一塊亮面 —— 那個關係是大塊面，縮到 212px 也讀得出。
- **牆**：燈箱／螢幕的冷白溢光讓上緣輕鬆過 B ≥ 212。✅
- **風險**：片子上的細節要收（只留顱側輪廓與一排牙），畫細會變雜點；
  絕不能畫成左右對照兩片（＝分格＋時間暗示）。

### Ⓑ 上下對得上（模型在手上）

醫師站著，雙手各拿上顎與下顎模型，正把它們**合起來**，一根手指停在後牙咬合的地方；
病人在旁邊湊近看。背後架子上還有幾副模型（元素少而大）。

- **對到**：直接畫那一頁的**重心那句話** —— 排整齊只是一半，上下要對得上。
- **視覺中心**：那副模型，可以放到畫面高的 ~35%（比頭大很多）——**三案裡 250px 最好讀的**。
- **風險**：模型容易被讀成「假牙」（會和日後植牙那張撞）。
  要畫得出牙弓＋弓絲，而且動作是**在手上對咬**，不是擺在桌上。

### Ⓒ 又跑回去的那一位

病人（曾經矯正過、三十幾歲）指尖輕碰自己的前牙、眉頭微皺；醫師在旁邊已經把片子調出來，
伸手示意「來，一起看一下」。

- **對到**：`cases` 第二句「矯正過一次，後來又跑掉了」＋ stance 的因果。
  這是全站唯一「失望過又回來」的讀者群，被看見的力道最強。
- **風險（三件，所以列為備案）**：① 動作太小，250px 下讀不出他在碰自己的牙；
  ② 容易變成懊悔的畫面（品牌那關要拉力不要推力）；
  ③ 一不小心就被讀成「別家做壞的」＝ 同業比較，紅線。
- **建議**：不單獨做，把它的**情緒**疊到 Ⓐ／Ⓑ 的病人身上（表情是「這次想弄清楚」）。

## 二之一、✅ 使用者選的：Ⓐ 的畫面 ＋ Ⓒ 的情緒（2026-08-24）

**畫面走 Ⓐ**（兩個人一起看一片亮著的側顱 X 光），
**病人的設定走 Ⓒ**（矯正過一次又跑掉、這次想弄清楚的那一位）。

這個組合解掉 Ⓒ 單獨做的三個風險，而且一個都沒有損失：

| Ⓒ 單獨做的風險 | 合併之後 |
| --- | --- |
| 動作太小，250px 讀不出「他在碰自己的牙」 | 畫面的可讀性由 Ⓐ 那塊發亮的片子扛，情緒只需要落在**表情與前傾的身體**上 |
| 容易變成懊悔的畫面 | 他不是在回想，是在**看下一步** —— 視線朝外、朝向片子，不是低頭 |
| 會被讀成「別家做壞的」 | 畫面上沒有「上一次」的任何痕跡（沒有對照片、沒有舊模型），只有這一次的片子 |

⚠⚠ 所以病人的情緒**只用三件事表達**：眉頭有一點點收、身體明顯前傾、
手上捏著自己查來的紙。**不畫懊悔、不畫嘆氣、不畫手碰牙。**

## 三、250px 下會讀到什麼（先想這件事，再想畫面好不好看）

訊息卡實測只有 **212 CSS px** 寬。能活下來的只有五塊：

    ① 畫面中央一塊**發亮的長方形**（看片燈箱）——整張圖唯一亮的東西
    ② 左邊一個穿白袍的人，手臂抬起、手指點在那塊亮面上
    ③ 右邊一個坐著、身體前傾的人，手上一疊白紙
    ④ 兩個人的臉都被那塊亮面打亮 ＝ 他們在看同一件東西
    ⑤ 右後方一個小小的人，在把模型放上架子

所以：**燈箱要大**（畫面高的 45%，212px 的卡上約 60px 高）、
**兩個人要大**（站著的醫師全身佔畫面高的 ~75%）、
片子上只留**顱側的輪廓線與一排牙**，不要畫細節 —— 細節在那個尺寸只會變成雜點。

⚠ 燈箱**只有一片**。兩片並排 ＝ 分格 ＋ 時間暗示，兩條紅線一起踩。

## 六、交件前要過的門檻（插畫師自己跑，不過就不拿出來）

| | 門檻 | 腳本 |
| --- | --- | --- |
| 無彩空白（S<12 且 L>80） | **< 5%** | `node drafts/og-measure.mjs <圖>` |
| 邊緣密度 | **≥ 30%** | `node drafts/og-measure-ink.mjs <圖>` |
| 三個人的線相差 | **< 20 階** | 同上 |
| 站著的醫師佔畫面高 | **≥ 70%** | 目視 ＋ 量 |
| 頂 17% 是不是純牆 | 沒有東西 | `og-measure.mjs` 的區塊表 |
| **頂 17% 的藍通道** | **B ≥ 212**（這一科的硬約束，第一節） | 同上 |

⚠ 這一張最可能出事的是**無彩空白**：冷白牆很容易掉進 S<12 那一格。
提示詞因此把牆寫成**帶一點藍的冷白 `#e6ebf0`**（S 約 22）而不是純白或中性灰。
第一版量出來若超過 5%，先看是不是牆被畫成了純白。

**我上一輪預測「深色面板會把密度拉上來」，量出來相反。** 成因：那張大面板
**內部是一整片平坦的深藍**（沒有明暗落差 ＝ 沒有邊），而且它還把背後有線條的房間遮掉了。
> **修正後的通則：邊緣密度是「邊」給的，不是「深」給的。**
> 一大片平坦的色塊，不管亮的暗的，都會把密度往下拉。
> 有效的是**很多有邊框、內部有記號的中小型物件** —— 正好是使用者這一輪要的。

### 這一版要改的（寫進 Ⓗ v2）

1. **螢幕變多變小**：一張主螢幕 ＋ **七張小螢幕弧形圍繞醫師**，大小各異（主的 20~40%）。
2. **每張螢幕都要有內容與符號** —— 這是密度的來源，也是使用者要的科技感。
3. ⚠⚠ **符號只准幾何形狀**（圓環、刻度、角度弧、十字準星、節點小圓、虛線路徑、對齊角括號），
   **不准任何像字母或數字的形狀** —— v7 的牙弓上已經長出幾個像字的小記號，
   那是規格 7（圖上不放字）的破口，而且模型畫中文一定壞掉。
4. **拿掉「提取一顆實體的牙」**（使用者指定）。改成**他的手指在螢幕平面上捏著一顆牙、
   沿著牙弓的弧線把它移到位** —— 牙齒始終是螢幕上的發光線稿。
5. **助理改成在遠處整理資料**：站在一排小螢幕前，把其中一張往旁邊推、其他疊成一落。
