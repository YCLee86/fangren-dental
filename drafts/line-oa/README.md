### 為什麼 hero 用 `assets/og-home.jpg`，不新畫一張

`1983年 中華路開業`／`9位 醫師駐診`／`5個 部定專科`），所以**不必再用文字列一次**。

・**尺寸驗過了，而且是往寬的方向**：那張圖是為 LINE 訊息卡設計的，
  CLAUDE.md 實測那個情境**只有 212 CSS px 寬**；Flex 的 mega bubble 約 300px，
  **大 42%**（1200×628 → 300×157px）。在更小的地方讀得懂，這裡一定讀得懂。

  ⚠ 這和 CLAUDE.md 那條「分享卡會被訊息 app 左右裁掉 10.7%」**不是同一件事** ——
  那條講的是**連結預覽卡**，Flex 的 hero 是自己指定比例的圖，不套那個裁法。
・**綠色標題列因此拿掉了**：那張圖的帶子上已經有標誌 ＋「芳仁牙醫診所」

## flex-preview.mjs —— 預覽產生器

```bash
node drafts/line-oa/flex-preview.mjs      # → drafts/line-oa/preview.png
```

兩張卡並排（帶圖／無圖），畫在 LINE 聊天室的黑底上，mega bubble ＝ 300px，DPR 3。

⚠⚠ **這是模擬，不是 LINE 自己的算繪結果。** 但它是**從那兩份 JSON 讀出來畫的**，
不是另外用 CSS 重寫一份 —— 理由同 CLAUDE.md 第八節那條「提案頁要擺真的產出檔」：
手寫一份對照版，哪天 JSON 改了這一頁就開始說謊。

尺寸依 LINE Flex 的公開規格近似（bubble mega 300px／字級 xxs 11 ~ xxl 27／
間距 xs 2 ~ xxl 20／按鈕高 sm 40）。
⚠ **原生 `button` 的圓角由 LINE 決定**，這裡畫 6px 近似；
我們自己用 `box` 做的那顆外框鈕，`cornerRadius: 8px` 是指定的，會照著畫。

踩過兩件（都寫在那支檔頭）：
・**playwright 是 CommonJS**，ESM 要整包 default import 再解構，具名匯入拿到 undefined。
・**一定要用 `headless_shell`**，完整版 `chrome` 畫出來會比 `--window-size` 少 87px
  而且不報錯（CLAUDE.md 第九節第 18 條）。
・`white-space: nowrap` 的文字要給 `min-width: 0`，否則 flex 容器會被內容撐開，
  兩張卡就不是同一個寬度了（第一版右邊那張比 300px 寬）。

七科一格，橫著滑（LINE 的 carousel，上限 12 格／整包 50KB，這一份 9.6KB）。
每一格：**著陸頁的分享圖 ＋ 那一科第一句病人的話 ＋ 該科的醫師與專長 ＋ 一顆該科顏色的按鈕**。

### 每一格的內容都是讀出來的，這一份不抄第二份

| 元素 | 來源 |
| --- | --- |
| 科別順序 | `index.html` 的 `.chips`（＝首頁那一排的順序） |
| 科別名（按鈕的字） | `topic-copy.mjs` 的 `label`（＝站上 chip 上那幾個字） |
| 按鈕的底色 | `index.html` 的 `[data-spec="x"] --accent`（＝按下 chip 填滿的那一階） |

| 醫師與專長 | `index.html` 的 `.doc`，配對規則和 `tools/topics.mjs` 第 7 步**逐字相同**（本科的醫師 ∪ 專長命中本科） |
| 圖 | `assets/og-topic-<spec>.jpg` |

### ⚠⚠ 那幾句是 LINE 自己的一套，**不是**著陸頁的文案（2026-08-27 使用者定的）

第一版用的是著陸頁的 `cases[0]`（病人的自言自語），**被退回了**。使用者的理由：

> 「網站是給還沒有病識感、或替家人找資源的人瀏覽用的，所以寫的時候是一個比較
> 模糊的印象；但**會加 LINE 的病人都已經是到診所才加的**，對疾病已經有基本的
> 認識。所以不要用那麼模糊的話，直接寫這個科別在做什麼、什麼樣的問題要找這個科別。」

**讀者不同，語域就不同**，這是這一輪最要記住的一條：

| | 著陸頁（站上） | LINE（這一份） |
| --- | --- | --- |
| 讀者 | 還沒有病識感、或替家人找資源 | **已經到過診所**，知道自己的問題 |
| 這一頁的工作 | 讓他覺得被看見 | 讓他知道**該點哪一格** |
| 語域 | 陪伴、模糊、病人的自言自語 | 指路、具體、第三人稱的狀況 |

⚠ **這不是放棄 COPY.md 第三節的品牌語氣** —— 不推銷、不誇大、不承諾療效、
不替病人做決定、不貶低同業，那幾條一條都沒鬆。換掉的只有「模糊」這一項。

⚠⚠ **每一句都要指得回站上已經有的東西**（全隊紅線第 11 條）。
`topic-copy-line.mjs` 裡每一科都註明那三句是從著陸頁哪幾句轉寫過來的，
**新的醫療主張一句都沒有加**。三個刻意沒寫的：
・牙周沒有寫「牙齦腫」（站上沒有那三個字，不要自己補症狀）
・矯正寫「適不適合」不寫「來不來得及」（年齡判準還沒問到診所）
・植牙沒有寫費用（自費結構還沒問到診所）
・口外沒有寫「不會痛」「不必硬來」（COPY.md 第九之十八節：否定句會把畫面塞進他腦子裡）

「這一科在做什麼」那一格用的是**醫師卡上的專長標記**（從 `index.html` 讀的），
不自己寫一句 —— 比較硬，也不會長出第二份真相。

### ⚠⚠ 第二輪：那個共用標題被退回了（2026-08-27）

第二版七張卡都掛「什麼狀況要找這一科」，使用者：
**「每個都寫『什麼狀況要找這一科』很機器人，要像親切專業的人對話的感覺。」**

→ 標題整個拿掉，改成 **`open`：七科各寫一句自己的開場**。
七張卡掛同一個標題，等於告訴人這是罐頭 —— 判準同 COPY.md 第九之十五節那張
七科節奏對照表：**看的是相鄰的卡片長不長得一樣**。

寫 `open` 的三條：

1. **是說出來的話，不是欄位名。** 唸得出來才算數。
2. **七句的形狀要不一樣** —— 現在是：邀請（一般）／說明順序（牙周）／
   反問（根管）／先試試看（兒牙）／補一件事（矯正）／一起看（植牙）／
   交給誰（口外）。不要七句都是「有這些狀況就來找我們」。
3. **每一句都要指得回著陸頁已經寫過的話**（各科的註解裡寫著是哪一句）。

### ⚠⚠⚠ 第三輪：一般牙科・定期檢查那一句寫壞了（2026-08-27）

第一句寫的是「沒有不舒服也可以來，先看一次比較放心。」使用者：

> 「這不是從民眾、一般人的角度會說的話。什麼叫做**先看一次比較放心**？
> 是已經知道可能有問題了，**先踩點看看**？好奇怪。」

拆開來是**兩個各自獨立的毛病**：

- **「先看一次」＝ 踩點。** 像是在試這間可不可以，不是在看牙。
- **「比較放心」＝ 預設他已經在擔心了。** 可是**定期檢查的人沒有在擔心** ——
  那正是他一直沒來的原因。**拿「擔心」當入口，這一科一定寫不對。**

⚠⚠ **通則（其他科也會踩）：先問「他為什麼會走進來」，再決定第一句怎麼寫。**
六科的入口是**症狀**（會痛、會腫、會搖、缺牙、排不整齊、拔不掉），
定期檢查沒有症狀 —— 它的入口是**他本來就會做的那件事：洗牙**。

⚠ 而且**民眾不說「定期檢查」，說的是「洗牙」「看牙」**。
站上那篇文章的標題就是〈半年一次的洗牙：健保給付的那一次，到底在做什麼〉，
而著陸頁 flow［半年］那一行**逐字就是答案**：

> 洗牙那半小時，順便把整口看一遍。

定案的 open 直接用它（前面補「半年一次的」當節奏），一句話同時做到三件：
用民眾的詞、不預設焦慮、說出這一科多做的那一件。

三行也一起換掉（舊的第二句「沒有不舒服，但想確認一下」是同一個毛病）：
`半年到了，想約洗牙` ／ `很久沒看牙，想整個檢查一下` ／ `想帶家裡的人一起來看`。

⚠ 沒有寫「健保」—— 健保的頻次對高風險族群不是半年一次
（著陸頁 flow［風險分級］就寫著「有人要更常來」），一句話講不清楚，留給那篇文章。

> 繼續根管治療就好，但**現在活髓放第一個又寫這麼多，會讓人誤解一直要求要做活髓**。」

⚠⚠ **這是「卡片會造成臨床困擾」的那一種問題** —— 不是文字不好聽，是寫得又前面
又長，等於替一個條件嚴苛的術式招客，然後病人帶著期待走進診間。

三件事一起做：

1. **移到第二句** —— 第一句改成長膿包那一段（那一群更大，而且不會催出需求）。
2. **砍短，並拿掉「留著神經的牙齒，比抽掉的耐用」** ——
   那句是真的，但它正是最會拉出需求的一句。文章裡還在，要深入的人看得到。
3. **補上邊界**：
   ・「會**評估**能不能保住」不是「有機會保住」
   ・「**條件嚴格**」
   ・「**不成功就接著做根管**」—— 這一句同時是安全網，讓人知道失敗不是走投無路。

定案：

> 抽過神經又長膿包，多半是末端的細小分支沒清乾淨 —— 重做或從牙根尖處理，還有機會。
> 蛀得很深、神經還沒受影響的，會評估能不能保住神經 —— 條件嚴格，不成功就接著做根管。

⚠⚠ **通則：一個成功率或適應症有限的術式，寫在卡片上要連邊界一起寫，
而且不要放第一句。卡片沒有空間承接期待，期待會直接落到診間。**

⚠ **沒有寫成功率的數字** —— 沒有問到診所自己的數據，不要引用文獻上的。

### 第十三輪：兒童牙科整張重寫（2026-08-27）

第一版的 open「孩子能配合多少，先試試看」兩個毛病：
① 它講的是**看診的方法**，不是這一科在解決什麼問題；
② 拿第十一輪那條通則去問一次「隔壁那科會不會也這樣講」——
   遇到不配合的大人，別科照樣這樣講，**所以它不夠格當這一科的開場**。

定案：

> **乳牙撐到換牙，恆牙才排得進來。**
> 不喊痛不代表沒事 —— 吃得慢、不愛吃，多半要檢查才看得出來。
> 能配合多少先試，真的不行才談舒眠。
> ・小孩喊牙痛，或不肯吃東西
> ・乳牙蛀了，不確定要不要處理
> ・看過牙，但不配合、沒處理成
> ・同一顆補了又掉

**open** ← flow［留位置］「乳牙留不住，先幫恆牙留著位置」。
和牙周的「地基」、根管的「看不見的那一段」是**同一個手法**：指向一個真的存在
的機制（乳牙在替恆牙占位），而且直接回答家長最大的猶豫 ——「反正會換，要不要處理？」
⚠ 寫成正面的「撐到換牙，恆牙才排得進來」，**不寫「乳牙不是反正會換」**。

**note①** 是這張卡最有價值的一句：**吃得慢、不愛吃，家長多半歸給挑食**，
不會想到牙齒（同牙周「痠軟就是牙周」那一條）。
⚠ 沒有寫「只用一邊咬」——那是站上**植牙**那一科的說法，兒牙頁面上沒有，不跨科搬。

**note②** ← flow［先試過］逐字改口語。
⚠⚠ **舒眠只寫「真的不行才談」，不介紹它怎麼做** —— 同第十二輪活髓那條通則：
適應症有限的處置，寫在卡片上要連邊界一起寫，而且不要放第一句。而且
「舒眠實際怎麼做（誰執行、怎麼監測、什麼情況才建議）」是 CLAUDE.md 第九節那張表裡
**還沒問到診所**的事，更不能自己補。
⚠ 用「舒眠」不用「鎮靜麻醉」——前者是著陸頁對家長用的字，後者是醫師卡上的
專長標記（那一欄照樣會顯示，兩邊各自對）。

**cases** ①③④ 維持；②新增，把 open 回答的那個猶豫寫成家長自己的話。

⚠ 版面沒有再長（1387 CSS px，和上一版相同）。

### ⚠⚠⚠ 第十四輪：兒牙那句舒眠**語氣站錯位置**（2026-08-27）

第一版寫「能配合多少先試，真的不行才談舒眠」。使用者：

> 「聽起來有種**想盡辦法嘗試**。實際狀況是**小孩可能已經很緊張恐懼，
> 光進診所就已經花了家長很大的心力**。語氣要改一下。我想到
> 『**孩子如果不能配合了，兒牙醫師可以在舒眠的狀況下處理**』。」

⚠⚠ **這一輪的毛病不是用詞，是語氣站錯位置。**「先試」把責任放在孩子與家長身上
（再努力一點看看），可是他們**光是走進診所就已經很費力了**。

定案：**先承認那件事，再把舒眠說成「還有這條路」，不是「失敗了才用的手段」。**

> 光是走進診所，有些孩子就已經很不容易了 —— 真的配合不來，兒牙醫師可以在舒眠的狀況下處理。

⚠ 後半是**使用者的原話**，逐字用。
⚠ 上一輪那條「適應症有限的處置要連邊界一起寫」**仍然守住** ——
邊界現在由「真的配合不來」承擔，而且**還是沒有介紹舒眠怎麼做**
（誰執行、怎麼監測，是 CLAUDE.md 那張表裡還沒問到的事）。

同一輪 note① 也改：「多半要檢查才看得出來」→「**牙齒可能出狀況了**」。
前者是**要他來檢查**（診所視角的行動），後者是**告訴他發生了什麼**（他的處境）。

⚠⚠ **站上著陸頁 flow［先試過］寫的正是被退回的那個語氣**
（「能配合多少先試，不行才談舒眠」）—— **同一個問題還留在網站上**，
要不要一起改是要問使用者的一題。

### ⚠⚠⚠ 第十五輪：兒牙那句舒眠**服務錯了對象**（2026-08-27）

第二版（「光是走進診所，有些孩子就已經很不容易了 ——」）當天又被退回，
兩個理由：**太長**，而且**服務錯了對象**。使用者：

> 「的確是為了已經找了很多家、然後被拒絕、找到一個出路的（家長）……但其實
> **也有很大一群是家長根本不知道小孩有多嚴重**，以為像以前一樣給看一下、補一下
> 就好了。但小朋友有時候**年紀太小、甚至兩三歲**，根本沒有辦法配合治療，要做
> 就只能舒眠的狀況。所以我覺得**這類群眾也加進來**，然後**要縮短那個支持性** ——
> 因為有很多家長會覺得這根本就不是（他的情況），他以為他小孩很輕微，
> 其實真的很嚴重，然後是沒有辦法做一般治療的。」

⚠⚠ **這一輪學到的：卡片上的一句話只服務得了一群人，要先確認是哪一群沒被接住。**

| 那一群 | 誰接住他 |
| --- | --- |
| **被拒絕過的家長** | `cases`③「看過牙，但不配合、沒處理成」**本來就接住了** |
| **不知道有多嚴重的家長** | 沒有人接 —— 而且**對他們講支持的話沒有用**（會覺得「這不是在講我」），要講的是**事實** |

定案：**先點名那一群 → 講事實 → 才給路**

> 兩三歲，或蛀得比想像中嚴重的，做不了一般治療 —— 兒牙醫師可以在舒眠下處理。

⚠ 「**兩三歲**」是使用者給的具體年紀，不寫成「年紀太小」——
具體的字他才對得上自己（同「彎／細／分支多」不寫「太複雜」那條）。
⚠ 「**比想像中**嚴重」是溫和地指出落差，不是責備；不寫「其實很嚴重」（那是在糾正他）。
⚠ 長度 44 → 36 字。

### ⚠⚠⚠ 第十六輪：舒眠是**常規**不是例外，還有第十二個角色（2026-08-27）

第三版「兩三歲……可以在舒眠下處理」與第四版「適不適合舒眠，由兒牙醫師評估」
都被退回。使用者：

> 「**兩三歲，那四歲呢？一歲呢？**」
> 「『適不適合舒眠』感覺有點在說『**不是真的能舒眠喔**』。實際的狀況是，
> **很多無法配合門診治療的案例都需要舒眠**，非常少數的先天缺陷或系統性疾病才不適合。」

**兩條通則，互為反面，要一起讀：**

| 那件事在臨床上 | 怎麼寫 | 例 |
| --- | --- | --- |
| **適應症有限** | 不放第一句、連邊界一起寫、寫成「由誰評估」 | 活髓 |
| **本來就是常規** | **不要用「適不適合」把它寫成難拿到的東西**，寫「多半需要」 | 這一群的舒眠 |

⚠ **「適不適合」把不確定性放在錯的地方**：真正少數的是**不適合的人**，
不是「能不能做這件事」。

⚠ **判準不是年齡是條件**（第三版那個錯我認）：「彎／細／分支多」是**描述那顆牙的
條件**（誰對得上誰就對得上），「兩三歲」是**一個門檻**（四歲、一歲的家長覺得
不關他的事）。**具體 ≠ 訂一個數字。**

定案：

> 蛀得比想像中嚴重、配合不了門診治療 —— 多半需要在舒眠下完成，兒牙醫師會先評估。

前半給常規（他知道自己多半就是這條路），後半留專業判斷（少數不適合的由醫師看），
**不在卡片上列先天缺陷或系統性疾病**（那是診間的事）。
「年紀還小」拿掉 —— **「配合不了門診治療」已經涵蓋它**，而且不再有會漏人的門檻。

使用者定的職責（原話）：**透過諮詢協助病患理解自己的狀況並做出適合自己的選擇；

### 第十七輪：植牙・假牙重建整張重寫（2026-08-27）

第一版 open「缺的、鬆的、補過的，可以一起看」**過不了第十一輪那條通則** ——
「可以一起看」一般牙科照樣講得通。

定案：

> **不只一顆要處理時，順序比選哪一種更重要。**
> 缺牙不會痛，但旁邊的牙會慢慢倒過去、骨頭也會流失；拖得愈久，治療愈複雜。
> 做假牙或植牙之前，牙周和蛀牙要先處理好。
> ・缺牙一段時間了　・假牙鬆了、不好咬　・問過幾個地方，說法都不一樣　・想把整口一起整理

**open** ← lead「從哪裡開始？」＋ flowTitle「要整理的話，順序大概是這樣」
＋ cases④「說法都不一樣」。
⚠⚠ 「**順序比選哪一種更重要**」是這一頁本來就有的立場 —— COPY.md 記著這一科的
設計決定是「**著陸頁給順序，文章給比較**」。它一次做三件事：回答「從哪裡開始」、
解掉「說法都不一樣」的焦慮、**把重點從「植牙 vs 假牙」移開**（那正是最容易變成推銷的地方）。

**note①** ← 〈缺牙之後〉（`posts/missing-tooth/`）的「不處理會發生什麼」：
鄰牙傾倒、對咬牙伸長、齒槽骨吸收、咀嚼負擔轉移；那一篇寫著
「**這個過程通常是無痛的**」與「**拖延的成本不是零，而是把日後的治療推向更複雜、
更貴的選項**」。
⚠⚠ 這是這一科「**病人自己解讀不了的訊號**」（同牙周的痠軟、兒牙的不喊痛）：
**不會痛，所以他以為沒事，可是一直在變。**
⚠ 只寫「治療愈複雜」，**沒有寫「愈貴」** —— 那一篇有寫，但錢寫在卡片上會變成壓力
（品牌紅線：不推銷），而且自費結構是那張表裡還沒問到的事。

**note②** ← flow［打底］。
⚠ 「地基」那兩個字**留給牙周那一張**，這裡只講順序 —— 兩張都用會把同一個比喻弄鈍。
⚠⚠ 這一句同時是**反推銷**的：**想做植牙的人，第一步不是植牙。**

⚠ **`全口重建` 只留在 `專長` 那一欄**，卡片上一個字都不多提 ——
同活髓那條：適應症有限、金額高的處置，不在卡片上招客。
這一張的兩句 note 反而是把人往「先打底」帶。

⚠ 版面沒有再長（1387 CSS px）。

### 第十八輪：口腔外科整張重寫（2026-08-27）

第一版 open「難拔的那幾顆，有醫師專門在處理」不算錯（頭銜寫成「醫師在做的那件事」），
但它講的是**誰**，不是**他自己判斷不了的事**。

定案：

> **要不要拔、好不好拔，看的是 X 光片：牙根的形狀、離神經多近。**
> 怕的多半是拔的那一下；真正決定那一週好不好過的，是拔完留下的傷口。
> 拔完留下的洞，齒槽骨會慢慢流失；需要的話會放填補材料。
> ・智齒腫過，反覆發作　・牙齒只剩牙根　・牙齒長不出來　・上次拔牙的感覺，到現在還記得

### 第十九輪：齒顎矯正整張重寫，七科到齊（2026-08-27）

這一科的難處：**站上刻意一個數字都沒有**（療程多久、回診間隔、自費結構、
實際提供哪些方式，四件都在 CLAUDE.md 第九節那張表的 `ask` 欄裡還沒問到），
所以能寫的**只有判斷與順序**，不能寫時間與錢。

**他到了哪一步**（臨床顧問的第一題）：**和口外相反** —— 口外的人已經決定要拔、
卡在怕；矯正的人**還沒決定**。〈牙齒矯正〉那一篇的開場就列出他沒問出口的四件：
「我這個年紀還來得及嗎、金屬和隱形到底差在哪、要花多久、**第一次去諮詢會不會
當場就被要求決定**。」

定案：

> **排整齊只是一半：咬得不對，拆掉之後很容易又跑回去。**
> 年紀不會讓牙齒失去移動的能力；前提是牙周要先穩定。

## 第二十一 ~ 二十三輪（2026-08-28）——矯正那一張收乾淨

一天之內來回五次，全部只動矯正那一張，其他六張一個字沒動。留下來的六條通則
都已經寫進 **TEAM.md 第 12 位（資深臨床顧問）** 的紅線。

### 二十一：三處

1. **「前提是牙周先穩定」會讓人猶豫。** 寫成前提就是一道關卡，成年人看完的
   反應是「那我到底能不能做」。臨床上要講的不是門檻，是**兩件事一起做**。
   ⚠ 和「條件句會招來反問」同一族，但傷害不同：那一條招來「那不能的呢」，
   這一條**讓本來能做的人自己退開**。
2. **「想先弄懂再決定」拿掉**，cases 剩三句（產生器允許三到四句）。
3. **「這幾科診所裡都有醫師」不成立。** 使用者：「有醫師不見得願意處理，
   或是有醫師不見得會好好合作。」有沒有人和接不接得起來是兩件事。
   改成寫協作**在做什麼**，落在**順序**上（和植牙那張同一個立場）。

### 二十二：「和青少年不一樣」整句拿掉

使用者：「不一樣是什麼意思，是更久還是有什麼我不知道的意外？那我還是不要想矯正好了。」

⚠⚠⚠ **「和 X 不一樣」是空的，而空的地方讀者會自己填最壞的。**
壞消息還能判斷，未知不能，所以**未知比壞消息更會勸退人**；
短文案沒有空間解釋差在哪，就不要提有差。

牙周的角色同時要講對：成年矯正是**多一道要考慮的因素**，不是「牙周不好就不要矯正」，
而且方向是正的（顧好牙周是為了矯正順利，不是矯正的阻礙）。

### 二十三：使用者自己定稿的兩件

**① 「比青少年」拿掉** —— 不必要的對照組。要講的是成年人自己要顧什麼，
青少年在不在場這句話都成立，帶進來只多一個要比較的對象。

**② 三句重排**（使用者直接給了排法）：

```
排整齊只是一半：咬得不對，拆掉之後牙齒很容易又跑回去。

矯正很少單獨進行：蛀牙、拔牙常常要先處理。
成年人矯正，還要注意到牙周狀況。牙周顧好，牙齒矯正才順利。

在芳仁，各科醫師會一起把療程的順序接起來。
```

- **牙周退出第一句的清單** —— 下一句整句就在講牙周，列在前面等於講兩次，
  而且會讓下一句讀起來像在重複。
- **「在芳仁…」自己站一行** —— 它是前面**兩句合起來**的回應，
  黏在第一句尾巴就只回應了蛀牙與拔牙，接不到牙周那一句。
- **通則在前、特例在後** —— 「矯正很少單獨進行」是整科的立場，
  「成年人還要顧牙周」是它底下的一種情況；倒過來排，讀的人要先接受一個
  不確定適不適用在自己身上的前提。

#### 兩案的整頁模擬

`health-carousel.mjs` 現在吃一個參數：

```bash

node drafts/line-oa/health-carousel.mjs b    # 案 B（原色＋深墨字）→ health-carousel-b.json

node drafts/line-oa/health-carousel.mjs bd  # B／D 成對比較（每張兩格，兩欄並排）
```

⚠ `bd` 是**比較用**：一張出兩格、body 多一行標記、不放收尾那一格，
共 16 格（超過 LINE 的 12 格上限，本來就不是拿去上線的）。
預覽器看到 `-bd.json` 會改排成兩欄，兩案才會左右並排在同一列。

⚠⚠ **案 D 五支全部過不了 AA**（白字對原色 1.74~2.32），是使用者指名要看的比較版本，
**不要當成可以直接上線的預設**。黃綠那支 1.74 最糟，白字幾乎浮在色塊上。
