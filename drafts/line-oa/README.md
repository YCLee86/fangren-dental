### 為什麼 hero 用 `assets/og-home.jpg`，不新畫一張

使用者 2026-08-27 問「圖片？診所創立年份？規模？幾位醫師？」——
**那三件事站上早就印在同一張圖上了**（`tools/og-home.mjs` 產的下緣三格：
`1983年 中華路開業`／`9位 醫師駐診`／`5個 部定專科`），所以**不必再用文字列一次**。

・**尺寸驗過了，而且是往寬的方向**：那張圖是為 LINE 訊息卡設計的，
  CLAUDE.md 實測那個情境**只有 212 CSS px 寬**；Flex 的 mega bubble 約 300px，
  **大 42%**（1200×628 → 300×157px）。在更小的地方讀得懂，這裡一定讀得懂。

  所以 `aspectMode: cover` **一邊都不會裁**。
  ⚠ 這和 CLAUDE.md 那條「分享卡會被訊息 app 左右裁掉 10.7%」**不是同一件事** ——
  那條講的是**連結預覽卡**，Flex 的 hero 是自己指定比例的圖，不套那個裁法。
・**綠色標題列因此拿掉了**：那張圖的帶子上已經有標誌 ＋「芳仁牙醫診所」
  ＋「雲林斗六・永樂街」，名字不必出現兩次；卡片也不會因為加圖而變更長。

## flex-preview.mjs —— 預覽產生器

```bash
node drafts/line-oa/flex-preview.mjs      # → drafts/line-oa/preview.png
```

兩張卡並排（帶圖／無圖），畫在 LINE 聊天室的黑底上，mega bubble ＝ 300px，DPR 3。

⚠⚠ **這是模擬，不是 LINE 自己的算繪結果。** 但它是**從那兩份 JSON 讀出來畫的**，
不是另外用 CSS 重寫一份 —— 理由同 CLAUDE.md 第八節那條「提案頁要擺真的產出檔」：
手寫一份對照版，哪天 JSON 改了這一頁就開始說謊。

尺寸依 LINE Flex 的公開規格近似（bubble mega 300px／字級 xxs 11 ~ xxl 27／
間距 xs 2 ~ xxl 20／按鈕高 sm 40）。
⚠ **原生 `button` 的圓角由 LINE 決定**，這裡畫 6px 近似；
我們自己用 `box` 做的那顆外框鈕，`cornerRadius: 8px` 是指定的，會照著畫。

踩過兩件（都寫在那支檔頭）：
・**playwright 是 CommonJS**，ESM 要整包 default import 再解構，具名匯入拿到 undefined。
・**一定要用 `headless_shell`**，完整版 `chrome` 畫出來會比 `--window-size` 少 87px
  而且不報錯（CLAUDE.md 第九節第 18 條）。
・`white-space: nowrap` 的文字要給 `min-width: 0`，否則 flex 容器會被內容撐開，
  兩張卡就不是同一個寬度了（第一版右邊那張比 300px 寬）。

## topics-carousel.mjs／.json —— 「診療項目」那一格

```bash
node drafts/line-oa/topics-carousel.mjs                       # → topics-carousel.json
node drafts/line-oa/flex-preview.mjs topics-carousel.json     # → preview-topics-carousel.png
```

七科一格，橫著滑（LINE 的 carousel，上限 12 格／整包 50KB，這一份 9.6KB）。
每一格：**著陸頁的分享圖 ＋ 那一科第一句病人的話 ＋ 該科的醫師與專長 ＋ 一顆該科顏色的按鈕**。

### 每一格的內容都是讀出來的，這一份不抄第二份

| 元素 | 來源 |
| --- | --- |
| 科別順序 | `index.html` 的 `.chips`（＝首頁那一排的順序） |
| 科別名（按鈕的字） | `topic-copy.mjs` 的 `label`（＝站上 chip 上那幾個字） |
| 按鈕的底色 | `index.html` 的 `[data-spec="x"] --accent`（＝按下 chip 填滿的那一階） |
| 那一句 | `topic-copy.mjs` 的 `cases[0]`（兒牙在 `groups[0].cases[0]`） |
| 醫師與專長 | `index.html` 的 `.doc`，配對規則和 `tools/topics.mjs` 第 7 步**逐字相同**（本科的醫師 ∪ 專長命中本科） |
| 圖 | `assets/og-topic-<spec>.jpg` |

文案一改、醫師一換、顏色一調，重跑就跟上。產生器有五道守門（chips 不是 7 科、
醫師不是 9 位、取不到那一句、配不到醫師或專長、圖不存在）任何一項不成立就 throw。

### ⚠⚠ 那幾句是 LINE 自己的一套，**不是**著陸頁的文案（2026-08-27 使用者定的）

第一版用的是著陸頁的 `cases[0]`（病人的自言自語），**被退回了**。使用者的理由：

> 「網站是給還沒有病識感、或替家人找資源的人瀏覽用的，所以寫的時候是一個比較
> 模糊的印象；但**會加 LINE 的病人都已經是到診所才加的**，對疾病已經有基本的
> 認識。所以不要用那麼模糊的話，直接寫這個科別在做什麼、什麼樣的問題要找這個科別。」

**讀者不同，語域就不同**，這是這一輪最要記住的一條：

| | 著陸頁（站上） | LINE（這一份） |
| --- | --- | --- |
| 讀者 | 還沒有病識感、或替家人找資源 | **已經到過診所**，知道自己的問題 |
| 這一頁的工作 | 讓他覺得被看見 | 讓他知道**該點哪一格** |
| 語域 | 陪伴、模糊、病人的自言自語 | 指路、具體、第三人稱的狀況 |

⚠ **這不是放棄 COPY.md 第三節的品牌語氣** —— 不推銷、不誇大、不承諾療效、
不替病人做決定、不貶低同業，那幾條一條都沒鬆。換掉的只有「模糊」這一項。

⚠⚠ **每一句都要指得回站上已經有的東西**（全隊紅線第 11 條）。
`topic-copy-line.mjs` 裡每一科都註明那三句是從著陸頁哪幾句轉寫過來的，
**新的醫療主張一句都沒有加**。三個刻意沒寫的：
・牙周沒有寫「牙齦腫」（站上沒有那三個字，不要自己補症狀）
・矯正寫「適不適合」不寫「來不來得及」（年齡判準還沒問到診所）
・植牙沒有寫費用（自費結構還沒問到診所）
・口外沒有寫「不會痛」「不必硬來」（COPY.md 第九之十八節：否定句會把畫面塞進他腦子裡）

「這一科在做什麼」那一格用的是**醫師卡上的專長標記**（從 `index.html` 讀的），
不自己寫一句 —— 比較硬，也不會長出第二份真相。

### ⚠⚠ 第二輪：那個共用標題被退回了（2026-08-27）

第二版七張卡都掛「什麼狀況要找這一科」，使用者：
**「每個都寫『什麼狀況要找這一科』很機器人，要像親切專業的人對話的感覺。」**

→ 標題整個拿掉，改成 **`open`：七科各寫一句自己的開場**。
七張卡掛同一個標題，等於告訴人這是罐頭 —— 判準同 COPY.md 第九之十五節那張
七科節奏對照表：**看的是相鄰的卡片長不長得一樣**。

寫 `open` 的三條：

1. **是說出來的話，不是欄位名。** 唸得出來才算數。
2. **七句的形狀要不一樣** —— 現在是：邀請（一般）／說明順序（牙周）／
   反問（根管）／先試試看（兒牙）／補一件事（矯正）／一起看（植牙）／
   交給誰（口外）。不要七句都是「有這些狀況就來找我們」。
3. **每一句都要指得回著陸頁已經寫過的話**（各科的註解裡寫著是哪一句）。

七句與它們的出處：

| 科別 | open | 出處 |
| --- | --- | --- |
| 一般牙科 | 半年一次的洗牙，順便把整口看一遍。<br>（另有 `note`：多久洗一次是看風險…） | flow［半年］逐字＋使用者 08-27 補的事實 |
| 牙周治療 | 牙齦的狀況，檢查過才知道到第幾期。<br>（另有 `note`：懷孕期間牙齦容易出狀況…） | flow［說明］＋使用者 08-27 補的事實 |
| 顯微根管 | 這顆還留不留得住，看清楚才知道。 | lead |
| 兒童牙科 | 孩子能配合多少，先試試看。 | flow［先試過］ |
| 齒顎矯正 | 排整齊之外，咬合也要一起看。 | stance |
| 植牙・假牙重建 | 缺的、鬆的、補過的，可以一起看。 | cases②＋flow［看全口］ |
| 口腔外科 | 難拔的那幾顆，有醫師專門在處理。 | stance＋close |

⚠ 四句刻意沒有那樣寫：
・根管不寫「盡量幫你留」（空白支票，COPY.md 第九之十六節）
・牙周不寫「早一點處理差很多」（療效暗示，站上沒這句）
・兒牙不寫「我們」（COPY.md 第九之十三節：回應句不要用「我們」）
・口外寫「有醫師專門在處理」＝ 頭銜寫成「醫師在做的那件事」（第九之十七節）

### 已知取捨

・**carousel 的每一格會被 LINE 拉齊成最高的那一格**，短的那幾格（顯微根管、口腔外科）
  body 底下會空一塊。預覽照著畫了，不是預覽做壞。
・**按鈕的白字對比**：一般 6.62／植牙 6.98／顯微根管 5.22／牙周 4.84／口外 4.82／
  矯正 4.57 都過 AA；**兒童牙科 `#c28229` 是 3.22**，低於 4.5 ——
  那是站上填色 chip 早就在用的同一顆（CLAUDE.md 定案表「兒牙填色上的白字」
  2026-08-08 使用者看過實際樣子之後決定維持）。**不要拿對比度來訂正它。**
・**科別名沒有寫在 body 裡**，因為分享圖的帶子上已經有了（同診所資訊卡那張的理由）。
  按鈕的字才是它，順便讓沒載到圖的人也知道這是哪一科。

### ⚠⚠⚠ 第三輪：一般牙科・定期檢查那一句寫壞了（2026-08-27）

第一句寫的是「沒有不舒服也可以來，先看一次比較放心。」使用者：

> 「這不是從民眾、一般人的角度會說的話。什麼叫做**先看一次比較放心**？
> 是已經知道可能有問題了，**先踩點看看**？好奇怪。」

拆開來是**兩個各自獨立的毛病**：

- **「先看一次」＝ 踩點。** 像是在試這間可不可以，不是在看牙。
- **「比較放心」＝ 預設他已經在擔心了。** 可是**定期檢查的人沒有在擔心** ——
  那正是他一直沒來的原因。**拿「擔心」當入口，這一科一定寫不對。**

⚠⚠ **通則（其他科也會踩）：先問「他為什麼會走進來」，再決定第一句怎麼寫。**
六科的入口是**症狀**（會痛、會腫、會搖、缺牙、排不整齊、拔不掉），
定期檢查沒有症狀 —— 它的入口是**他本來就會做的那件事：洗牙**。

⚠ 而且**民眾不說「定期檢查」，說的是「洗牙」「看牙」**。
站上那篇文章的標題就是〈半年一次的洗牙：健保給付的那一次，到底在做什麼〉，
而著陸頁 flow［半年］那一行**逐字就是答案**：

> 洗牙那半小時，順便把整口看一遍。

定案的 open 直接用它（前面補「半年一次的」當節奏），一句話同時做到三件：
用民眾的詞、不預設焦慮、說出這一科多做的那一件。

三行也一起換掉（舊的第二句「沒有不舒服，但想確認一下」是同一個毛病）：
`半年到了，想約洗牙` ／ `很久沒看牙，想整個檢查一下` ／ `想帶家裡的人一起來看`。

⚠ 沒有寫「健保」—— 健保的頻次對高風險族群不是半年一次
（著陸頁 flow［風險分級］就寫著「有人要更常來」），一句話講不清楚，留給那篇文章。

### ⚠⚠⚠ 第四輪：一般牙科補上「頻率看風險」（2026-08-27，**新的診所事實**）

使用者（他是牙醫，他就是出處）：

> 「定期檢查除了半年洗牙，還包括**三個月一次的洗牙、塗氟**，對應到的是
> **牙周病、齲齒風險較一般人高的族群**。這個觀念比之前不一樣 —— 以前覺得好好
> 清潔牙齒就都會好好的，但現在的概念是**有些人即便好好清潔，牙齒只要一點小動靜
> 就會有問題**。（最直接的類比就是疫苗：以前以為打一次終生有效，現在觀念也不
> 一樣了，要打多重劑次、隔幾年補打。）**現在那三點寫得很好，儘量保留；
> 這個觀念是加進來，不是整個取代。**」

做法（**加**不是**換**）：

- `open` **一個字沒動**（他說寫得好）＝ 這一次來會發生什麼事。
- 新增 `note`（open 底下、不加粗的第二句）＝ **多久來一次是看風險**，
  把三個月與塗氟帶出來：「多久洗一次是看風險 —— 有人半年，有人三個月，需要時再加上塗氟。」
- `cases` **原本三句全部保留，只加第四句**給高風險那一群：
  「刷得很認真，還是一直蛀牙或牙周發炎」—— 用他自己的話講，讓他在四句裡找得到自己。

⚠ `note` 寫成**正面敘述**（「多久洗一次是看風險」），不寫「不是每個人都半年一次」
—— 否定句會把舊觀念再講一次（同 COPY.md 第九之十八節）。
⚠ **沒有寫「健保」**：三個月一次與塗氟的給付條件跟族群、年齡都有關，
一行字講不清楚，講一半比不講糟。留給文章。
⚠ **已知取捨**：加了 note 與第四句之後，一般牙科變成最高的一格，
carousel 齊高 → 其餘六格底下各多空約 130px。這是為了這一塊內容付的版面代價。

### ⚠⚠ 這一輪冒出一件要問使用者的：站外比站內新

**著陸頁目前只寫了這件事的一半** —— `tools/topic-copy.mjs` 的 flow［風險分級］是
「有人半年一次就夠，有人要更常來」，**沒有三個月、沒有塗氟、沒有那個觀念**。
LINE 卡片現在講得比站上多，**違反社群這一號的核心職責（站外和站內講同一套話）**。

兩條路，要使用者決定：
① 把這一塊補回 `tools/topic-copy.mjs` 的一般牙科（flow［風險分級］那一行，
   或另開一行），跑 `node tools/topics.mjs` 讓著陸頁跟上；
② 卡片先這樣，站上下一輪再一起處理。

**建議①** —— 這是這一科真正的差異點，只放在 LINE 上等於浪費，
而且它正好補掉 CLAUDE.md 第九節那張表裡「一般牙科・還沒問到的：高風險回診怎麼排」。

### ⚠⚠⚠ 第五輪：懷孕放進**牙周**那一張（2026-08-27，**又一塊新的診所事實**）

使用者：「像懷孕也有**懷孕緊急牙周處理**和**懷孕三個月洗牙**，這也是一種牙周風險。」

**放牙周不放一般牙科**，兩個理由：

1. **他自己就是這樣框的** —— 「這也是一種牙周風險」。
2. **懷孕是身分不是症狀。** 一般牙科那張的四句都是「狀況」（半年到了、很久沒看、
   帶家人、認真刷還是出事），懷孕的人要先判斷自己算不算高風險才對得上；
   放在牙周這一張，她**直接認出自己**。

加了兩樣：
- `note`：「懷孕期間牙齦容易出狀況 —— 洗牙三個月一次，急性的可以先處理。」
- 第四句：「懷孕後牙齦變得容易腫」

⚠⚠ **版面上這一塊是免費的**：牙周原本比一般牙科矮，carousel 本來就要拉齊 ——
補上之後兩張差不多高，**七格的高度一格都沒有再長**（1200 CSS px，和上一版相同）。
**通則：carousel 裡「比最高那一格矮」的卡，加內容不用付版面的錢。**

⚠ 三件刻意沒寫：
・**不寫「不必等到生完」** —— 那個誤解確實存在，但否定句會把它再講一次
  （同 COPY.md 第九之十八節）。改成正面的「急性的可以先處理」。
・**不寫「健保」、不寫產後多久之內** —— 給付的條件與期間要問過才寫得準。
・**不寫「最」**（「牙齦最容易出狀況」）—— 品牌紅線。

⚠ 這一塊**站上的牙周著陸頁也沒有**（`tools/topic-copy.mjs` 的 perio 從頭到尾
沒有提到懷孕），和一般牙科那一塊是同一個問題 —— 站外比站內新，見上一節那一題。
