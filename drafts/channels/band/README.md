# 那條「標誌排成一排」的分隔線

使用者 2026-09-18：「這個帶子 logo 我很喜歡　另外存起來　我在新的對話開啟要用」。
成品第一次出現在櫃檯小立牌上（`/preview/line-stand/`，抬頭「芳仁牙醫有 LINE 囉」底下那一條）。

## 三個檔

| 檔 | 內容 |
| --- | --- |
| `fangren-band-27.svg` | **定案那一條**：27 顆，**七顆套各自的科別色**、其餘 20 顆淡墨 `#aeafab` |
| `fangren-band-27-mono.svg` | 同一條，**整條 `currentColor`** —— 貼到哪裡都只要設一個 `color` |
| `fangren-band-9.svg` | **一個基數（9 顆）**，`currentColor`。接得起來的最小一段 |

`viewBox` 是 `0 0 5488 214`（9 顆那一份是 `0 0 1865 214`），**寬度自己撐滿容器、高度照長寬比**。
印在 98 mm 寬上量到：帶子高 **3.82 mm**、一顆最高 **1.91 mm**。

## 用它的時候要知道的五件

1. ⚠⚠⚠ **九個形狀等墨不等高**（61~107，差 1.75 倍）—— 那九個寬度是按**墨的面積**正規化算的，
   所以九顆一樣重、但不一樣高。**每一格的框固定成最高的那一顆、形狀垂直置中**，
   不然就是一排高高低低（已經烘進 SVG 裡了，別自己重排）。
2. ⚠⚠ **四邊與顆與顆之間那五個間隔是同一個算式給的**（最高那一顆的 0.5 ＝ 53.5 單位），
   四邊的留白**烘在 viewBox 裡** —— 外面**不要再加 padding**，加了兩邊就和中間不一致。
3. ⚠⚠⚠ **牙洞是 `fill-rule: evenodd` 挖穿的**：填什麼顏色，洞就透出底下那一層。
   **不要另外畫一塊當洞**（畫出來一模一樣，但形狀一改就會對不準，而且不報錯）。
4. ⚠ **牙洞在這個尺寸印不出來**（98 mm 上只有 0.15 mm，平版印刷大約守得住 0.2~0.3）——
   那一排讀起來是「一條有節奏的線」而不是 27 個標誌，**那正是分隔線要的**，但要知道它會發生。
5. ⚠⚠ **顆數只給基數的整數倍**（27 ＝ 9×3）：那三條相鄰的限制在**接縫上也要成立**，
   整數倍等於把同一段接回它自己。要別的長度就改 `stand-card.json` 的 `順序案` 另寫一份，
   **不可以就地截一段**（截口沒有人驗過）。

## 排法與套色的規則（都在資料裡，不是排好看就算）

- 順序（基數 9）：`r1c3 r1c1 r2c3 r2c2 r3c1 r3c3 r1c2 r3c2 r2c1`
  —— 三條限制：**同一顆形狀不相鄰、三顆最長的不相鄰、顏色相同的兩顆不相鄰**。
- 套色：**七科各一顆**，位置 **2／6／9／14／17／21／25**（口外・牙周・矯正・一般牙科・顯微根管・贋復・兒牙），
  間隔 4／3／5／3／4／4。⚠ 每一顆套的就是**它自己那個形狀的科別色**，一個色碼都不抄第二份。
  ⚠⚠ 「不要太集中」＝ 最小間隔 ≥3 顆、「不要太規律」＝ 相鄰兩個間隔相同的最多一對；
  **「一對都不准相同」做不到**（每一科的三顆固定落在 mod 9 的同一個餘數上），那是幾何不是沒挑好。
