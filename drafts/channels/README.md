## 二、拿到數字之後，兩件事的看法變了

### 2-1　⚠⚠ 「電話忙線」不是偶發，是**結構性**的

六個月 1,886 通 ≈ **每月 314 通** ≈ 每個看診日 **15 通**，而且**這還只是
「從 Google 商家檔案按撥號」那一種**（沒有算直接輸入號碼、名片、招牌、
回診卡上抄的）。

→ 第一輪那位病人說「我有打電話，忙線中」**不是運氣不好**。
→ 所以 LINE 那三則裡「打電話最快」這個指引**是對的，但不夠**：
   我們寫的「忙線就隔幾分鐘再撥」是把問題丟回給他。
   **這一條要帶回去問使用者**：診所要不要考慮第二線、語音信箱、或讓
   LINE 的「不克前往，預約改期」按鈕真的接得住（見 3-2）。

### 2-2　Google 商家檔案**不是「還沒開始做」，它一直是最大的入口**

CLAUDE.md 第九之〇節寫著它「投報率最高、只有使用者能做」，從 8/17 擱到現在。
現在有數字了：**六個月 14,973 個人看過那張檔案、1,886 通電話從那裡打出來。**
相較之下官網是「找資料的人」才會去，商家檔案是「現在就想打電話的人」。

**它值得一個固定的維護節奏**（照片、看診時間、評論回覆），這是第 11 號角色
接下來要提的第一件事。⚠ 但**不要動到看診時間的三組不一致**（CLAUDE.md 第十節）——
那要使用者先定案哪一組才是對的。

### 3-2　⚠⚠⚠ 最要緊的一件：**病人其實可以在 LINE 上改期**

那張卡最底下就是「**不克前往，預約改期**」。
**這推翻了我們前十輪的前提** —— 我們一路寫「改約或取消，打電話最快」，
是因為以為 LINE 上做不到。

**在問清楚之前，三則文案先不要改**（那個按鈕點下去實際會怎樣？
開一個改期頁面？還是只是通知診所、仍然要等人回電？）。
問到之後：

- 如果**真的可以自己改期** → 三則的主要動作要從「打電話」改成
  「**用提醒卡上的按鈕**」，電話退成備援。這會讓那 1,886 通電話少掉一部分。
- 如果**只是通知診所**、還是要等回電 → 文案維持現在的寫法，
  但要在綁定完成那一則講清楚「按了會怎樣」，不然他按了就以為改好了。

### 3-3　這張卡本身的問題（等上面那題有答案再一起處理）

| | 問題 | 為什麼要緊 |
| --- | --- | --- |
| **語序** | 「〔病人姓名〕 **提醒您**，您的看診時間將至」—— 姓名放在「提醒您」前面，讀起來像**那個人在提醒你** | 這是全帳號曝光最高的一句話。⚠ 但**名字本身是必要的**，見 3-4 |
| **名稱不一致** | 標題寫「**斗六**芳仁牙醫診所」，站上與其他所有地方都是「芳仁牙醫診所」 | 同一間診所兩個名字 |
| **語氣** | ⚠ emoji、👉、紅字、驚嘆號 —— 和站上「不推銷、講究」的調子落差很大 | 病人一年看到很多次，這才是他心中芳仁的樣子 |
| **就診須知第 2 條** | 「有發燒/咳嗽/呼吸道症狀等，請來電改約」—— 和底下那顆「不克前往，預約改期」按鈕**互相矛盾**（一個叫他打電話、一個叫他按按鈕） | 兩條路同時給，他會愣住 |
| **⚠ 能不能改** | **未知** —— 這張卡是廠商系統產的，文字改不改得動要問廠商 | 決定這一條是待辦還是已知限制 |

選單上寫的是那四個字，文案跟它不一致病人就會找不到。

### 6-2　⚠⚠⚠ 最要緊的發現：**我們的四格圖有 3/4 格和選單重複**

用一則只出現一次的訊息，去重複一個永遠都在的東西，等於浪費那一則。

→ **建議把招呼訊息的圖從四格換成已經做好的兩格版**
（`preview/line-reply/rich-2.png`：照片＋大大的 `05-5339369`）。理由：

### 6-3　實測證實：**選單按下去會留下一則「像病人自己傳的」訊息**

截圖逐幀可見：病人按了選單 → 聊天室出現一則**綠色（病人側）**的
`[約診紀錄查詢]` → 系統回「您尚未有任何預約😃」。

**這正是第十二節說的那個代價，現在有實證了。** 兩件跟著確定：

1. **關鍵字回應確實會蓋過一般自動回應** —— 那則 `[約診紀錄查詢]` 沒有跳出
   通用的自動回應，只回了查詢結果。**所以「格子連到自己的資訊圖卡」那條路可行。**
2. 廠商用的關鍵字**帶方括號**（`[約診紀錄查詢]`）—— 那是刻意讓它看起來像系統指令、
   不像人講的話。**我們日後若自己設關鍵字，可以照這個慣例**，
   或者反過來用自然語句，兩種都行，但**同一個帳號裡要一致**。

### 6-4　病人端看得到「此官方帳號正在自動回覆訊息」

截圖的標題列下方就寫著這一行（LINE 自動加的，管理者關不掉）。
→ **病人本來就知道這是自動回覆。** 所以我們那句「這個帳號的訊息是系統自動發送的」
**不是新資訊**，它的價值只在「接下來告訴他怎麼找到人」。
⚠ 這不代表要拿掉那句 —— 但可以更短，重點放在後半（打電話 / 按按鈕）。

### 6-5　推播的實況：**診所本來就沒有在做定期推播**

使用者：「診所沒有特別推播什麼。只有重大事件例如**調漲掛號費**和**颱風天休診**，
**針對有被影響的約診病人群發訊息**。」

⚠⚠ **所以第四節那條「第一次推播就當一次實驗」的建議整條收回。**
診所不想做定期衛教推播，這是一個決定，不是一個缺口。而且：

- **封鎖率 2.2% 的謎解開了** —— 它低，正是因為**幾乎不發**。
  這個數字現在可以當成「不打擾」的證據，不是「還沒被考驗」。
- **他們現在的做法其實是對的**：**分眾**（只發給受影響的人）而不是全體轟炸。
  這和站上「不推銷」的品牌是一致的。**不要去說服他們開始做內容行事曆。**

→ **這個角色接下來該做的，不是「提議推播」，而是把他們真的會用到的那兩種
群發訊息寫好備著**：**颱風／臨時休診**、**費用或制度異動**。
那兩種都是「事情發生時很急、很容易寫得慌張」的訊息，事先寫好模板才有用。

## 七、⚠ 2026-09-02（更晚）：那個名字是**病人**，而且它是必要的

使用者確認：「提醒上的名字是病人。」

### 7-1　所以我前面的判讀要修正一半

我原本只說「語序讓姓名讀起來像在提醒你」，暗示那個名字可有可無。**錯了。**

截圖的聊天室名稱是「**〔家長姓名〕(哲&丞)**」，而提醒卡上的名字是那兩個小孩其中一個
—— 也就是說：**一個 LINE 帳號在收好幾個家人的約診提醒**。
那個名字是在回答「**這一次是誰要看牙**」，對帶小孩的家長是**非有不可的資訊**。

⚠ **通則：看到一個欄位覺得多餘之前，先問它在替誰回答什麼問題。**
這一次差一點就把唯一能分辨「是哪個小孩」的線索當成贅字。

### 7-2　所以要修的不是名字，是**那一句的語序**

| | |
| --- | --- |
| 現在 | `〔病人姓名〕 提醒您，您的看診時間將至　請問您是否前往看診呢？` |
| 問題 | 名字直接接「提醒您」，讀起來像**那個人在提醒你**；帶兩個小孩的家長還要多讀一次才知道是誰 |
| 建議 | `提醒您：〔病人姓名〕的看診時間快到了` —— 名字留著，位置換到它該在的地方（受詞） |

⚠ 這張卡是廠商系統產的，**改不改得動要問廠商**（同 3-3 的其他四項）。

### 7-3　跟著要問的一題：**家人可以綁在同一個帳號嗎？**

既然一個帳號收得到多個家人的提醒，那綁定那一關是怎麼運作的？

- 如果**一個帳號可以綁多位家人** → 綁定完成那一則應該多一句
  「**家人的約診也可以綁在這個帳號**」，那比「把連結轉給他」更省事，
  也更貼近實際在發生的事（家長替全家管）。
- 如果**一個帳號只能綁一支手機／一個人** → 那第十六節那句
  「把這個連結轉給他就好」就是對的做法，維持原樣。

**這一題沒答案之前，兩則文案都不動。**

4. ⚠⚠ **「不克前往，預約改期」按下去，只是系統上顯示取消。** 原話：
   > 「診所會看狀況打給病患確認。如果是重要療程，會儘量在原訂約診時間前和病患
   > 了解確認、改約（**有時候也有誤按**）。如果是定期檢查、回診，就沒有硬性一定要在
   > 原訂約診時間前和病患確認（因為有時候病患就不接電話了，我們當作他不想再來）。
   > **基本上，在這裡按取消已經違反診所和病患的預約協議**（至少兩天前不含假日要更改、
   > 取消，否則日後不受理預約）。」

### 8-1　⚠⚠⚠ 結構性矛盾：**系統在期限那一刻，才遞給他一顆違規的按鈕**

| | |
| --- | --- |
| 診所的協議 | 更改／取消要在看診日的**兩天前（不含假日）** |
| 提醒的時機 | **看診前 48 小時** ＝ 剛好兩天 |
| 中間若跨假日 | 「不含假日」會把期限再往前推 → **提醒送到時已經過期** |

**所以那張卡送到病人手上的那一刻，期限剛好到期或已經過期**，
而卡片底下就放著「不克前往，預約改期」。
**等於系統在邀請病人做一件違反協議的事**，事後再由診所打電話去收拾
（重要療程要追、定期檢查就算了）。這解釋了為什麼那顆按鈕還是得靠人工回電。

### 8-2　所以文案怎麼寫（已定稿）

- **三則都不把那顆按鈕寫成改約的管道。** 改約一律指向電話與「兩天前」的規則。
- **也不寫「不要按那顆按鈕」** —— 否定句只會讓它更醒目（COPY.md 第九之十七節 B），
  而且它在某些情況（誤按、真的臨時有事）仍然是有用的訊號。
- **把規則放在他還來得及的時候講** ＝ **綁定完成那一則**（那是他綁完、還沒排下一次約診的時候）。

### 8-3　真正的解不在文案，在**時機**（建議，要問廠商）

既然提醒卡的文字可改、發送時機多半也可設，**最根本的做法是把提醒拆成兩次**：

| | 什麼時候 | 這一則的工作 |
| --- | --- | --- |
| 第一次 | **看診前 3～4 天**（在期限之前） | 「要改期還來得及」—— 那顆按鈕**這時候才有意義** |
| 第二次 | **看診前一天或當天早上** | 「別忘了」—— 這一則**不要放改期按鈕**，只留「我會到」 |

現在的單一次 48 小時提醒，同時想做這兩件事，所以兩件都做不好。
⚠ **要問廠商：發送時機可不可以設定、可不可以發兩次。**

### 8-4　提醒卡的建議改法（文字可改，但臨床那兩行要醫師點頭）

```
芳仁牙醫診所                    ← 拿掉「斗六」，和站上一致

提醒您：〔病人姓名〕的看診時間快到了
2026/07/14（二）19:15

看診前請帶健保卡，並戴上口罩。
如果有發燒或咳嗽，請先打電話給診所。

［我會到］
［不克前往］
```

改了五件：
1. **標題**「斗六芳仁牙醫診所」→「芳仁牙醫診所」（站上與其他地方都是這個）。
2. **語序**：名字從「提醒您」前面移到受詞的位置 —— **名字留著**（一個帳號收好幾個
   家人的提醒，那是唯一能分辨是誰的線索，見第七節）。
3. **拿掉 ⚠🚬👉📅 與紅字**：這是一年會看到很多次的訊息，它就是病人心中芳仁的樣子。
4. **就診須知兩條併成兩句白話**，不用編號、不用『』。
   ⚠ 這兩行是**臨床內容**，要醫師點頭才能改。
5. ⚠ **「請來電改約」與「預約改期」的矛盾解掉**：發燒那句改成「先打電話給診所」，
   和底下的按鈕不再打架。

⚠ 按鈕的文字與行為要不要改（例如按了之後系統回一句「我們收到了，會再打電話
跟你確認」），**等 8-3 的時機問題有答案再一起處理** —— 時機不改，按鈕怎麼寫都尷尬。

→ **「不說」只有在對方本來就不期待回覆時才成立。**
這也回頭確認了第十五節那個結論：說，但說在第二句、而且下一行立刻給出口。

### 12-2　可以學的兩件

1. **資訊那一則乾淨得像一張名片** —— 名稱、電話、時間、例外，**四行、沒有一句廢話**。
   我們現在的兩層清單已經是同樣的效果，而且只佔一個泡泡，**所以不必學它分成兩則**
   （分兩則會再多一個泡泡，第十三節那個「兩則加起來」的帳要重算）。
2. ⚠⚠ **「國定假日除外」** —— 它用一句話把例外講掉。

### 12-3　⚠⚠⚠ 那句「國定假日除外」讓我們發現一個**沒問到的診所事實**

想照抄的時候去查站上怎麼寫，結果是：

> `index.html` 的門診表底下：**「國定假日與各科特別門診請來電確認。」**

**站上寫的是「請來電確認」，不是「休診」。** 所以：

- ❌ **不能寫「國定假日休診」** —— 那是我們自己推的（全隊紅線第 11 條：診所的事實
  沒問到就不要寫）。
- ❌ 也不能寫「國定假日請來電確認」—— 那一段本來就在講「打電話給診所」，
  變成「打電話問電話有沒有人接」，繞回自己。
- ✅ **這一輪的做法**：把那一行補成「**週一至週五**開診時間內都有人接」，
  週末與國定假日交給站上的門診表（那一項本來就連過去）。

→ **加進待問清單：國定假日到底休不休診？** 問到之後這一句才寫得完整。

### 12-4　沒有學的

「誠摯」「蒞臨」「探索愛馬仕世界」「將會為您提供服務」—— 這是精品的距離感，
和 COPY.md 第十節那條（貼近在地、不端著）正面衝突。**語氣一個字都不抄。**
