# 口腔外科預約協議 —— 內文文案（2026-08-26）

診所要印／要放進簡報的一張表，**不是網站上的東西**，所以住在 `drafts/`
（同 `drafts/door-notice/` 的處理方式，見 CLAUDE.md 第八節那個「第三種結局」）。

原始版面：一張表五列（約診／電話確認／提醒回覆／自動刪除／違約），
右欄是「內文說明」。使用者當時的狀態：**第 1 列是空的**，第 2 列寫著
「看診前 7 天診所致電確認，若未接到，隔天需主動回電。」他覺得後半句太白話。

---

## 一、第 1 列「約診」的內文

使用者要講的三件事：① 口腔外科是**長時間療程** ② **很多病人在等**
③ 請**先確認自己的行程再約**，臨時更動會影響其他人。

### ⚠ 先講一個不要寫的寫法

「**將影響其他患者的權益**」這一類的句子不要用。理由和 COPY.md 第九之十七節 B
（換框，不是換字）是同一條：那句話**在他還沒做錯任何事的時候就先指控他一次**，
讀起來是公告欄的聲音，不是這間診所的聲音。

**做法：只把事實擺出來（這個時段是單獨留給你的、後面有人在排），
讓他自己接到結論。** 不必替他把後果講完。

### 三案

**甲（推薦，三行）**

```
口腔外科療程較長，
每個時段都是單獨保留給一位患者。
請先確認行程，再與診所約定時間。
```

**乙（兩行，字數最接近其他四列）**

```
口腔外科療程較長，時段單獨保留給一位患者。
請確認行程後再與診所約定時間。
```

**丙（把「有人在等」講出來）**

```
口腔外科療程較長，後面也有患者在等。
約診前請先確認行程，儘量避免臨時更動。
```

⚠ 三案都**沒有寫「不要爽約」「否則……」** —— 那是第 5 列「違約」的工作，
在第 1 列先講一次會讓整張表從頭到尾都在防人。

## 二、第 2 列「電話確認」

原句：`看診前7天診所致電確認，若未接到，隔天需主動回電。`

兩個要修的地方：
- **「若未接到」的受詞掉了** —— 沒接到什麼？（同 COPY.md 第九之十七節 F：
  省主詞可以，省受詞不行。）
- **「需主動」是命令的語氣**，而且「主動」這兩個字暗示他本來會被動。

### 三案

**甲（推薦）**

```
看診前 7 天，診所會致電與您確認。
若當日未能接通，請於隔日回電診所。
```

**乙（最精簡，字數與其他列一致）**

```
看診前 7 天診所致電確認。
未能接聽時，請於隔日回電。
```

**丙（回電有地方可打，適合印出來貼）**

```
看診前 7 天，診所會致電與您確認。
若未能接通，請隔日回電 (05)533-9369。
```

⚠ 電話的顯示寫法全站統一是 `(05)533-9369`（CLAUDE.md 第六節），
印刷品照這個寫，不要寫成 `05-533-9369`（那是給機器讀的）。

---

## 三、順手提兩件（使用者自己決定要不要改）

1. **第 3 列與第 4 列的時間對不太起來。**
   第 3 列是「看診前 **48 小時**」提醒，第 4 列是「約診**前一天**未回覆」就刪除。
   48 小時 ＝ 兩天，「前一天」是第幾天不容易算。建議第 4 列改成
   **「約診前 24 小時仍未回覆到診確認，系統不保留約診。」** ——
   和第 3 列的 48 用同一種單位，讀者一看就知道自己有一天可以回。

2. **最底下那句（金句）**

   使用者提供了同一套簡報其他頁的範例，格式歸納出來是
   **七字 ＋ 七字、押尾韻，前半句講處境或事實，後半句講做法或結果**：

   | 那一頁 | 金句 |
   | --- | --- |
   | 假牙材質 | 假牙材質千百種，工法選對用長久 |
   | 牙周治療 | 重度牙周耐心治，齒齦繼續進行式 |
   | X 光輻射 | 游離輻射有點怕，測量對照放心拍 |
   | 拔牙術後 | 辛苦手術免驚慌，照護做好不徬徨 |
   | 預約協議（現行） | 約診守信負責任，牙齒健康最順心 |

   ⚠ 現行那一句畫面上是「約診守信**信**責任」，**信**字重複了一次，
   應該是「負責任」。不論最後選哪一句，這個字先改掉。

   ### 六案（都是七字＋七字、押尾韻）

   | | 金句 | 韻 | 收在哪件事 |
   | --- | --- | --- | --- |
   | **甲（推薦）** | 約好時間準時到，療程順利免煩惱 | 到／惱 | 五條規則的總結 |
   | **乙** | 口外療程時間長，準時到診免緊張 | 長／張 | 第 1 條（療程長）的理由 |
   | **丙** | 這段時間為您留，準時前來免等候 | 留／候 | 時段是保留給你的 |
   | **丁** | 電話確認先回覆，看診當天不耽誤 | 覆／誤 | 第 2、3 條（回電與回覆） |
   | **戊** | 一人一診時間長，準時報到最穩當 | 長／當 | 一個時段一位患者 |
   | **己** | 守好約定的時間，牙齒健康看得見 | 間／見 | 守時 → 健康，接得最遠 |

   ⚠ 六案都**沒有**「務必」「請勿」「否則」—— 那三個詞是第 5 列的工作，
   金句是整張表的收尾，收在「順」上比收在「罰」上好。
