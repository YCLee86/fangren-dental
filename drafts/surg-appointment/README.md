# 口腔外科預約協議 —— 內文文案（2026-08-26）

診所要印／要放進簡報的一張表，**不是網站上的東西**，所以住在 `drafts/`
（同 `drafts/door-notice/` 的處理方式，見 CLAUDE.md 第八節那個「第三種結局」）。

原始版面：一張表五列（約診／電話確認／提醒回覆／自動刪除／違約），
右欄是「內文說明」。使用者當時的狀態：**第 1 列是空的**，第 2 列寫著
「看診前 7 天診所致電確認，若未接到，隔天需主動回電。」他覺得後半句太白話。

---

## 一、第 1 列「約診」的內文

使用者要講的三件事：① 口腔外科是**長時間療程** ② **很多病人在等**
③ 請**先確認自己的行程再約**，臨時更動會影響其他人。

### ⚠ 先講一個不要寫的寫法

「**將影響其他患者的權益**」這一類的句子不要用。理由和 COPY.md 第九之十七節 B
（換框，不是換字）是同一條：那句話**在他還沒做錯任何事的時候就先指控他一次**，
讀起來是公告欄的聲音，不是這間診所的聲音。

**做法：只把事實擺出來（這個時段是單獨留給你的、後面有人在排），
讓他自己接到結論。** 不必替他把後果講完。

### 三案

**甲（推薦，三行）**

```
口腔外科療程較長，
每個時段都是單獨保留給一位患者。
請先確認行程，再與診所約定時間。
```

**乙（兩行，字數最接近其他四列）**

```
口腔外科療程較長，時段單獨保留給一位患者。
請確認行程後再與診所約定時間。
```

**丙（把「有人在等」講出來）**

```
口腔外科療程較長，後面也有患者在等。
約診前請先確認行程，儘量避免臨時更動。
```

⚠ 三案都**沒有寫「不要爽約」「否則……」** —— 那是第 5 列「違約」的工作，
在第 1 列先講一次會讓整張表從頭到尾都在防人。

## 二、第 2 列「電話確認」

原句：`看診前7天診所致電確認，若未接到，隔天需主動回電。`

兩個要修的地方：
- **「若未接到」的受詞掉了** —— 沒接到什麼？（同 COPY.md 第九之十七節 F：
  省主詞可以，省受詞不行。）
- **「需主動」是命令的語氣**，而且「主動」這兩個字暗示他本來會被動。

### 三案

**甲（推薦）**

```
看診前 7 天，診所會致電與您確認。
若當日未能接通，請於隔日回電診所。
```

**乙（最精簡，字數與其他列一致）**

```
看診前 7 天診所致電確認。
未能接聽時，請於隔日回電。
```

**丙（回電有地方可打，適合印出來貼）**

```
看診前 7 天，診所會致電與您確認。
若未能接通，請隔日回電 (05)533-9369。
```

⚠ 電話的顯示寫法全站統一是 `(05)533-9369`（CLAUDE.md 第六節），
印刷品照這個寫，不要寫成 `05-533-9369`（那是給機器讀的）。

---

## 三、順手提兩件（使用者自己決定要不要改）

1. **第 3 列與第 4 列的時間對不太起來。**
   第 3 列是「看診前 **48 小時**」提醒，第 4 列是「約診**前一天**未回覆」就刪除。
   48 小時 ＝ 兩天，「前一天」是第幾天不容易算。建議第 4 列改成
   **「約診前 24 小時仍未回覆到診確認，系統不保留約診。」** ——
   和第 3 列的 48 用同一種單位，讀者一看就知道自己有一天可以回。

2. **最底下那句（金句）**

   使用者提供了同一套簡報其他頁的範例，格式歸納出來是
   **七字 ＋ 七字、押尾韻，前半句講處境或事實，後半句講做法或結果**：

   | 那一頁 | 金句 |
   | --- | --- |
   | 假牙材質 | 假牙材質千百種，工法選對用長久 |
   | 牙周治療 | 重度牙周耐心治，齒齦繼續進行式 |
   | X 光輻射 | 游離輻射有點怕，測量對照放心拍 |
   | 拔牙術後 | 辛苦手術免驚慌，照護做好不徬徨 |
   | 預約協議（現行） | 約診守信負責任，牙齒健康最順心 |

   ⚠ 現行那一句畫面上是「約診守信**信**責任」，**信**字重複了一次，
   應該是「負責任」。不論最後選哪一句，這個字先改掉。

   ### ⚠ 2026-08-26 追加的概念：專科醫師這件事

   使用者要把「口腔外科**專科醫師**執行、術後比較不會腫痛、不容易傷到神經或
   穿破鼻竇，是**難得的醫療資源**」放進來，但**不要寫成「不要隨便找他」**，
   要收在「讓療程順利」上。

   ⚠⚠ **兩件不能寫進去的**：

   1. **「不會腫痛」「不會傷到神經」「不會鼻竇穿孔」不能寫。**
      那是替臨床結果打包票（COPY.md 第九之十七節 C），而且醫療法第 86 條
      禁止誇大療效。**能寫的是「醫師在做的那件事」** ——
      「術前先評估神經與鼻竇的位置」是事實描述，不是承諾。
   2. **不要寫「別的地方做不到」「比較穩」「更專業」。**
      那是同業比較（COPY.md 第六節紅線）。**寫自己做得來就好，
      不寫別人做不來。**「難得」要落在「診次有限」，不是落在「別家沒有」。

   ### 六案（都是七字＋七字、押尾韻，含專科概念）

   | | 金句 | 韻 | 重心 |
   | --- | --- | --- | --- |
   | **甲（推薦）** | 難得約到專科診，準時到場最安心 | 診／心 | 難得 ＋ 守約 ＋ 安心，三件都在 |
   | **乙** | 專科診次得來難，準時赴約心也安 | 難／安 | 同上，語氣更台一點 |
   | **丙** | 口外專科手夠穩，準時赴約更放心 | 穩／心 | 收在醫師的手上 |
   | **丁** | 專科拔牙穩又準，約好時間要當真 | 準／真 | 最直白 |
   | **戊** | 口外專科診次少，約好時間別遲到 | 少／到 | ⚠「別遲到」帶一點責備，要斟酌 |
   | **己** | 專科出手先評估，準時赴約好上路 | 估／路 | 收在「術前先評估」那件事 |

   ### 原本那六案（不含專科概念，留著備用）

   | | 金句 | 韻 |
   | --- | --- | --- |
   | 庚 | 約好時間準時到，療程順利免煩惱 | 到／惱 |
   | 辛 | 口外療程時間長，準時到診免緊張 | 長／張 |
   | 壬 | 這段時間為您留，準時前來免等候 | 留／候 |
   | 癸 | 電話確認先回覆，看診當天不耽誤 | 覆／誤 |
   | 子 | 一人一診時間長，準時報到最穩當 | 長／當 |
   | 丑 | 守好約定的時間，牙齒健康看得見 | 間／見 |

   ⚠ 全部十二案都**沒有**「務必」「請勿」「否則」—— 那三個詞是第 5 列的工作，
   金句是整張表的收尾，收在「順」上比收在「罰」上好。

## 四、第 1 列「約診」的內文 —— 加進專科概念之後（2026-08-26 改寫）

上面第一節那三案沒有提到專科醫師，加進來之後改成這兩案：

**甲（推薦，四行）**

```
口腔外科由專科醫師執行，
術前會先評估神經與鼻竇的位置，
每個時段都單獨保留給一位患者。
請先確認行程，再與診所約定時間。
```

**乙（兩行，字數接近其他四列）**

```
口腔外科由專科醫師執行，術前先評估神經與鼻竇的位置。
每個時段單獨保留給一位患者，請確認行程後再與診所約定。
```

⚠ 兩案都**只寫醫師做了什麼**，沒有寫「所以不會腫、不會傷到神經」——
理由見上面那兩條。也沒有寫「這是難得的資源，請不要浪費」，
那句話會讓還沒做錯事的人先被說一次；「單獨保留給一位患者」已經把稀有講完了。

## 五、第 4 列「自動刪除」改寫（2026-08-26）

使用者：「第 4 點現在看起來像是**只有**約診前一天沒回覆才不保留，
但其實第 2 點的電話沒回電也一樣不保留 —— 是**雙重機制**。
第 4 點要改成：第 2、3 項**其中一項沒做**，就都不會再保留。」

⚠ 兩個小陷阱：
- **改寫時不要把「什麼時候截止」弄丟。** 原句唯一交代期限的就是「約診前一天」，
  只講「任一項未完成」的話，讀者不知道自己還有多久可以補。
- **兩件事要用第 2、3 列自己的標籤稱呼**（「電話確認」「提醒回覆」），
  讀者的眼睛才接得回去，不必用「第 2、3 項」讓他往回數。

### 三案

**甲（推薦，期限留著）**

```
電話確認與提醒回覆，任一項未完成，
系統將於約診前一天自動釋出時段。
```

**乙（最短，字數最接近其他四列）**

```
電話確認、提醒回覆，
任一項未完成即不保留約診。
```

**丙（用編號，最不會誤讀）**

```
第 2、3 項任一項未完成，
系統不保留您的約診。
```

### 順帶一個標籤的建議

第 4 列的標籤「**自動刪除**」可以改成「**自動釋出**」：
- 「刪除」是對他做的一件事，「釋出」是那個時段去了哪裡 ——
  剛好接回第 1 列的「單獨保留給一位患者」與後面在等的人。
- 語氣從罰則變成流程，而規則本身一個字都沒有放寬。
