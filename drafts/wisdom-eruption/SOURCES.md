## ⚠⚠⚠ 2026-09-21 第二輪：「年齡不是風險因子」那句話**已經從文章裡拿掉**

**使用者（牙醫師）退回第一版的標題與收尾方向**：

> 「〈…二十歲拍的那張 X 光，還不是定局〉這樣寫會誤導。
> 　等到三四十或甚至年紀更大再處理，骨頭更硬更難弄，術後腫痛也會更明顯，
> 　為了這個影響工作生活不見得比較好。趁年輕骨頭軟早點處理，
> 　對手術難度和病患本身日常影響還是比較小。」

**他是對的，而且錯的是我加的那一句，不是原稿。** 經過如下：

1. 原稿只寫「時機有差」。
2. 我查到台灣那份健保資料（PLOS ONE 2021）寫著「**年齡不是乾性齒槽炎／術後感染／顳顎關節症狀的風險因子**」，
   就拿它去補了一個但書，說「手術難度」和「併發症機率」是兩件事。
3. ⚠⚠ **那是過度推論。** 那份資料統計的是「**要不要多跑一趟門診處理併發症**」，
   它的終點裡**沒有**手術難度、沒有磨掉多少骨頭、沒有腫幾天、沒有幾天不能正常吃飯。
   拿一份沒有量那些東西的資料，去反駁「趁年輕拔比較輕鬆」，等於用 A 的數字否定 B 的問題。
4. 而且它**擺錯了位置**：放在收尾，讀者讀完最後的印象就是「不急」。
   連標題（「還不是定局」）也是同一個方向。

**這一輪的處理**：

| | |
| --- | --- |
| 標題 | 〈二十歲拍的那張 X 光，還不是定局〉→ **〈該拔的趁早，該留的看著它〉**。⚠ 2026-09-22 使用者再收短成 **〈智齒要不要拔：該拔的，要趁早〉** |
| 那句「年齡本身並沒有成為這幾項併發症的風險因子」 | **從文章裡整句拿掉。**它是真的，但在這一篇裡只會被讀成「所以不急」。台灣那兩個數字（3.6%／0.17%）**留著**，用途改成「這是可預期的手術」，並明講那份資料統計的是併發症發生率 |
| 新增一節〈確定要拔的話，愈早愈省事〉 | 三條，各自有出處：骨頭軟硬／手術性拔除的難度／術後腫痛與恢復。收在「要請幾天假、幾天不能好好吃飯」 |
| 第二節的收尾 | 「先追蹤是有實證基礎的做法」→ 改成**只對一種人成立**（沒症狀＋刷得到＋沒影響前一顆），其餘的「不是再等等看，是該安排處理了」 |

⚠⚠ **不要再把那句「年齡不是風險因子」加回文章裡。** 它留在這一份就好。
⚠ 同理，追蹤研究那三份（芬蘭 ×2、紐西蘭）**沒有被拿掉也沒有被削弱** ——
它們回答的是「**這顆會不會自己長出來**」，不是「**該不該拖**」。兩個問題不一樣，
第二輪要做的正是把它們分開，不是刪掉其中一邊。
