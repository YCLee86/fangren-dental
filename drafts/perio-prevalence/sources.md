# 〈「八成人有牙周病」：這句話少說了一半〉查核表

2026-09-19。稿子在同一個資料夾的 `index.html`，預覽頁在 `preview/perio-prevalence/`。

## 這一篇的由來與第二版改了什麼

素材是使用者提供的一份學術體例的跨國比較稿（七節、含文獻清單）。
**第一版照那份的軸寫**——各國盛行率為什麼差一倍以上（個案定義、量幾顆牙、
缺牙的存活偏差）。**使用者退回**：

> 「太學術了　民眾不需要知道這個測量差異　這好像在說癌症盛行率有高有低
> 因為檢測到的癌細胞數不一樣　聽起來失焦沒什麼意義。民眾要知道牙周病是
> 很普遍的疾病　但有分嚴重度，這篇文章的目的是讓民眾提升關注自己牙齒健康
> 不是教他們理解怎麼測量」

**第二版整個換軸**：普遍是真的（78.7%）→ 但嚴重的不到一成 → 分成四層 →
中間幾層幾乎不痛 → 骨頭不會長回來所以早一層差很多 → 誰走得比較快 →
要量哪三件。**方法學那一整塊（跨國表、三件量測差異、CPITN／CDC-AAP／2018 分類、
存活偏差）全部拿掉，一個字都沒有留。**

## 第三版：語氣（2026-09-20）

使用者再退回一次，這一次不是內容是**語氣**：

> 「文章有些文字語氣會讓人誤以為牙周病不嚴重可以放心　調整一下　我們要說的是
> 牙周病是很普遍的疾病　但有分嚴重度　不要等到重度再來處理已經太慢了　中度就
> 應該要積極處理　輕度更要經常性牙周照護　大家對這個疾病要很有警覺性　不是因為
> 老牙齒才掉光　資料顯示是年輕就有　只是很少數人年輕就很嚴重　而隨著年齡時間
> 累積到老才掉光」

改掉的六處（第二版讀起來像安慰的地方）：

| 第二版 | 第三版 |
| --- | --- |
| 「嚴重的不到一成」停在那裡 | 補上「那不到一成並不是另外一群人，是從比較輕的階段一年一年走過來的」 |
| 「多數人落在前面比較輕的階段…最有機會回到原點」 | 「現在還不算嚴重不是可以放著的理由，它的意思只有一個：**現在還按得住**」 |
| 表格第三欄「通常要做的」 | 改成「**這一層該做什麼**」，四層各自寫出行動與急迫性 |
| 輕度：「控制得住」 | 「刮乾淨之後**固定回診做牙周照護**，這一層最需要的是持續，不是清一次就結束」 |
| 中度：「有些區域需要手術」 | 「**要積極處理**…拖著不動，等於每年都在扣掉骨頭」 |
| 重度：「目標變成保住哪幾顆」 | 「**走到這一層才開始處理，已經太慢了**」＋原句 |
| 收尾「絕大多數人現在都還來得及」 | 「輕度要靠固定的牙周照護按住，中度就要積極處理，等到重度才動手已經太慢」 |

另外把年齡那一段**升成獨立一節〈牙齒不是老了才掉的〉並提到第二節**（原本只是
「誰走得比較快」底下的一個項目），講法照使用者口述的那條時間軸：年輕就有、
年輕就嚴重的是少數、多數人一年一年累積到六七十歲一次結算。標題也跟著換成
〈八成人有牙周病：牙齒不是老了才掉，是從年輕累積來的〉。

⚠ 新增的醫學敘述兩句，都是教科書級共識、不是新引用：**進展速度因人而異**
（2018 分類的 Grading 就是在講這件事）、**牙周病是會復發的慢性病**
（站上〈牙周病治療〉已經寫過同一句）。

## 第四版：兩種機制（2026-09-20）

使用者補的醫學內容：

> 「『牙齒不是因為老才掉的，是因為這個病在嘴裡待了三、四十年』——這是其中一個
> 很常見的機制。另外一個機制是　到了某個狀態或年齡　身體對牙周環境反應出現變化
> （例如懷孕）」

做法：〈牙齒不是老了才掉的〉那一節底下拆成兩個 `h3`（站上七篇文章已經在用 `h3`，
樣式 `assets/style.css` 第 616 行，顏色 `--accent-deep`，沒有新增任何顏色）：

- **機制一：時間一年一年累積**（原本那一段搬過來，補一句「慢到幾乎沒有哪一天會
  讓人覺得今天變嚴重了」）
- **機制二：身體對牙周環境的反應變了**（新寫）——同樣的清潔、同樣的牙菌斑，
  發炎卻更強。懷孕是最典型的，另外列青春期、更年期、血糖控制變差、生病或用藥
  讓抵抗力下降。特徵是**變化來得比較快**，而且常發生在本來就有輕度牙周炎的人身上。

收尾把兩種機制綁在一起：「時間會累積，而人生某些階段會讓同一份牙菌斑造成更大的
傷害」，並點出準備懷孕、血糖正在調整、抵抗力較差的時期是值得先做一次牙周檢查的時機。
「重點整理」那一題與「血糖沒有控制好的人」那一項也跟著補。

### 機制二的查核

| 主張 | 判定 | 依據 |
| --- | --- | --- |
| 懷孕時荷爾蒙變化會放大牙齦對原有刺激的反應，孕期牙齦紅腫與流血常見 | ✅ 有據 | 牙周文獻的共識：雌激素與黃體素受體存在於牙周組織，孕期的發炎反應與牙菌斑量**不成比例**地被放大 |
| 少數人會長出容易出血的肉芽（妊娠性肉芽腫／pyogenic granuloma） | ✅ 有據 | 同上；文獻描述為「對局部刺激的過度反應，受孕期荷爾蒙影響」 |
| 孕期的牙齦變化多半在生產後緩解 | ✅ 有據 | 文獻：探測深度增加、探測出血、齦溝液流量等變化產後消退 |
| 已經傷到的骨頭不會跟著回來 | ✅ 有據 | 與本篇「骨頭不會自己長回來」同一條，站上〈牙周病治療〉已寫過 |
| 青春期、更年期、血糖控制變差、抵抗力下降屬於同一類 | ✅ 教科書級共識 | 2018 分類的 Grading 與「宿主反應修飾因子」就是在講這一群 |

❓ **刻意沒有寫的一件**：健保對孕婦洗牙間隔的規定（常聽到「孕婦每 90 天可洗牙一次」）。
**沒有查證，也不知道現行條文**，所以頁面上只寫「是值得先做一次牙周檢查的時機」，
沒有提任何給付或間隔。要寫的話得先查健保署現行規定，而且回診間隔屬於診所事實。

### 合併時動的兩件（都要讓使用者知道）

1. **⚠ Löe 那一條的句子微調過。** 他貼的版本是「一項…長期研究顯示，**老年人**牙齒掉得多，

   改成：研究「記錄的就是這個過程：在沒有接受治療的情況下，牙周的附連與牙齒是一年一年
   地流失的」，後面關於老年人的那一句維持原樣、但**不再掛在那份研究名下**（那是本文自己
