# 〈「八成人有牙周病」：這句話少說了一半〉查核表

2026-09-19。稿子在同一個資料夾的 `index.html`，預覽頁在 `preview/perio-prevalence/`。

## 這一篇的由來與第二版改了什麼

素材是使用者提供的一份學術體例的跨國比較稿（七節、含文獻清單）。
**第一版照那份的軸寫**——各國盛行率為什麼差一倍以上（個案定義、量幾顆牙、
缺牙的存活偏差）。**使用者退回**：

> 「太學術了　民眾不需要知道這個測量差異　這好像在說癌症盛行率有高有低
> 因為檢測到的癌細胞數不一樣　聽起來失焦沒什麼意義。民眾要知道牙周病是
> 很普遍的疾病　但有分嚴重度，這篇文章的目的是讓民眾提升關注自己牙齒健康
> 不是教他們理解怎麼測量」

**第二版整個換軸**：普遍是真的（78.7%）→ 但嚴重的不到一成 → 分成四層 →
中間幾層幾乎不痛 → 骨頭不會長回來所以早一層差很多 → 誰走得比較快 →
要量哪三件。**方法學那一整塊（跨國表、三件量測差異、CPITN／CDC-AAP／2018 分類、
存活偏差）全部拿掉，一個字都沒有留。**

## 第三版：語氣（2026-09-20）

使用者再退回一次，這一次不是內容是**語氣**：

> 「文章有些文字語氣會讓人誤以為牙周病不嚴重可以放心　調整一下　我們要說的是
> 牙周病是很普遍的疾病　但有分嚴重度　不要等到重度再來處理已經太慢了　中度就
> 應該要積極處理　輕度更要經常性牙周照護　大家對這個疾病要很有警覺性　不是因為
> 老牙齒才掉光　資料顯示是年輕就有　只是很少數人年輕就很嚴重　而隨著年齡時間
> 累積到老才掉光」

改掉的六處（第二版讀起來像安慰的地方）：

| 第二版 | 第三版 |
| --- | --- |
| 「嚴重的不到一成」停在那裡 | 補上「那不到一成並不是另外一群人，是從比較輕的階段一年一年走過來的」 |
| 「多數人落在前面比較輕的階段…最有機會回到原點」 | 「現在還不算嚴重不是可以放著的理由，它的意思只有一個：**現在還按得住**」 |
| 表格第三欄「通常要做的」 | 改成「**這一層該做什麼**」，四層各自寫出行動與急迫性 |
| 輕度：「控制得住」 | 「刮乾淨之後**固定回診做牙周照護**，這一層最需要的是持續，不是清一次就結束」 |
| 中度：「有些區域需要手術」 | 「**要積極處理**…拖著不動，等於每年都在扣掉骨頭」 |
| 重度：「目標變成保住哪幾顆」 | 「**走到這一層才開始處理，已經太慢了**」＋原句 |
| 收尾「絕大多數人現在都還來得及」 | 「輕度要靠固定的牙周照護按住，中度就要積極處理，等到重度才動手已經太慢」 |

另外把年齡那一段**升成獨立一節〈牙齒不是老了才掉的〉並提到第二節**（原本只是
「誰走得比較快」底下的一個項目），講法照使用者口述的那條時間軸：年輕就有、
年輕就嚴重的是少數、多數人一年一年累積到六七十歲一次結算。標題也跟著換成
〈八成人有牙周病：牙齒不是老了才掉，是從年輕累積來的〉。

⚠ 新增的醫學敘述兩句，都是教科書級共識、不是新引用：**進展速度因人而異**
（2018 分類的 Grading 就是在講這件事）、**牙周病是會復發的慢性病**
（站上〈牙周病治療〉已經寫過同一句）。

## 二、原稿裡刻意沒有寫進頁面的

- **跨國比較表（美國 42%／德國 95.1%／香港 57.4%／新加坡 77.6%）與整套方法學**
  —— 使用者退回的那一塊。日後若要寫給同業看，那是另一份文件，不是這一篇。
- **GBD 2021 的 12.50%、逾 10 億人**（PMID 39192495，查證過是對的）：全球數字，
  這一篇的讀者用不到。
- **Rose 的預防弔詭**（Int J Epidemiol 1985;14(1):32-38）：概念留著
  （「絕大多數人現在都還來得及」那一段），學說名不上頁面。
- **德國的給付政策、香港的逐牙位數字、原稿第七節「對台灣工作的意涵」整節。**
- **吸菸 1.48 倍、刷牙流血 2.34 倍那兩個危險比**：第一版寫進去了，第二版拿掉
  —— 換軸之後那一段變成「誰走得比較快」，用白話講原因比給危險比有用，
  而且那兩個數字正好是還沒逐字核對的那一份。
