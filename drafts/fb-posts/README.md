# 診所臉書貼文的格式（2026-09-04 定，寫任何一則之前先讀）

依據是**診所自己已經發過的那一則**（〈根管治療的生物陶瓷〉，2026-08 底發，
使用者 2026-09-04 貼進對話）。全文逐字存在下面。

## ⚠⚠ 和「假牙材質」那則舊貼文不是同一種聲音

`drafts/crown-materials-post.md` 那一則（金屬／全鋯冠／金屬燒瓷）是
**更早、還沒收斂的版本**：表情符號、「大比拚」「小秘密」、編號＋👉⚠️🛑💡、
末尾三行 🏥📞📍。**生物陶瓷那一則把這些全部拿掉了。**
新的貼文一律照生物陶瓷那一則，不要照假牙材質那一則。

## 骨架（生物陶瓷那則逐段拆出來的）

| 段 | 做什麼 | 長度 |
| --- | --- | --- |
| 1 | **病人自己的一句話**，用「」框起來。是**做完治療、問題還在**那種困惑，不是衛教問句。**問句或陳述句都可以**，判準是「他真的會這樣講嗎」；用詞照他的（台語思路的疊字、口語都行——引號裡是病人的話，COPY.md 第十節那條管的是診所的敘述語言） | 1 行 |
| 2 | **這個治療實際上在做什麼** → 所以「還會出事」代表什麼 | 3 行 |
| 3 | **「臨床上最常見的三件：」＋ 三項**，每項一行，括號放補充。⚠ 三項如果是**療程**（不是失敗原因），每一項要帶一句「**為什麼需要它**」，不能只列名字 | 4~9 行 |
| 4 | **轉折句** —— 把三項收成一個判斷，並替某件事重新定位（「它不是附加選項，本來就是這個封閉系統的一部分」）。**一到三行都可以**，⚠ 2026-09-04 使用者把水雷射那則收成一句，並要求**用肯定句**：講「清創是什麼」，不要講「水雷射不是什麼」——不用否定句去防守一個自己在做的項目 | 1~3 行 |
| 5 | **標題那個主角**負責的是哪一段，以及它憑什麼 | 4 行 |
| | ⚠⚠ **主角是「病人要自費決定做不做」的療程時，這一段不寫**（2026-09-04，水雷射那則）——獨立一段講它的好處，讀起來就是在賣它。改成收進第 3 段清單裡，用破折號接在它補的那一項後面。⚠ **判準不是字數，是「有沒有自己的段落」**——收在別段裡當補充，機轉與效果都可以寫；一旦另起一段，一句話也像廣告。**篇幅不要是三項裡最長的那一段**。生物陶瓷可以獨立寫，是因為它是材料不是選購項目 | 0 行 |
| 6 | `芳仁牙醫診所・雲林斗六永樂街` | 1 行 |
| 7 | 主題標籤 6~7 個，**由窄到寬**，`#斗六牙醫 #雲林牙醫` 收尾 | 1 行 |

**本文合計約 270~300 字**（不含標籤）。

## 硬規則

1. ⛔ **一個表情符號都不要用。**
2. ⛔ **沒有電話、沒有地址門牌、沒有「預約專線」、沒有「歡迎預約」。**
   落款只有 `芳仁牙醫診所・雲林斗六永樂街` 那一行。
3. ⛔ **本文裡不放網址。** 連結是**診所自己在貼文底下的第一則留言**：
   > 如果牙齒有類似的狀況，完整的一篇在這裡。
   > https://fangren.net/posts/<slug>/
   （臉書會在留言底下自動長出網站的預覽卡，標題與縮圖來自那一頁的 og:*。）
4. **手動斷行**，一行一個子句，不寫成整段。行長大約 12~22 個字。
5. **破折號用「——」**，不用「-」。
6. ⛔ **不要把幾個療程講成「層次」「第一層／第二層」**（2026-09-04）——那隱含高低與進階，
   讀起來像三段升級；它們其實是三種不同狀況要做的事。用「三件事」這種平的說法。
   （「第一步」可以，那是時間順序不是階級。）
7. **不比較同業、不承諾療效、不寫促銷語**（COPY.md 第三節、TEAM.md 第 11 號角色的紅線）。
8. **不寫術式的步驟**（「局部麻醉、分區進行」「翻瓣清創之後」都被使用者拿掉了）——讀者要的是這一步換到什麼，不是怎麼做的。
9. **事實只能來自那一篇自己說過的話**；診所事實（費用、要跑幾次、回診間隔）沒問到就不寫。
   ⚠ **也不要替某個療程標「自費」**（2026-09-04 使用者拿掉「自費的水雷射」那三個字）。
   健保有給付這種對讀者是好處的事可以寫，反過來標價目性質的標籤不寫。
10. **配圖是站上那一篇的 HERO 插畫**（生物陶瓷那則用的就是 `hero-bioceramic-photo-*`）。

## 為什麼是這個形狀（不要順手改回去）

- **開場那句是「做完了怎麼還這樣」**，不是「你知道嗎」——前者是他此刻真的在想的事，
  後者是衛教的聲音（COPY.md 第九之一節）。
- **中段那個轉折句是整則的重心**：它把一個常被當成「加購」的東西
  （牙套／水雷射）重新定位成「本來就是這件事的一部分」。
  **每一則都要有這一句**，找不到就表示這一篇還沒想清楚要說什麼。
- **連結放留言**：本文不帶外連，觸及比較不會被壓；而且留言那一句
  「如果牙齒有類似的狀況」本身就是篩選——不是要所有人點。

## 範本原文（〈根管治療的生物陶瓷〉，逐字）

```
「都已經抽過神經了，怎麼又長膿包？」

根管治療是把發炎壞死的牙髓與感染源清除之後，
把整個根管系統密封起來。
所以幾年後又出狀況，多半代表那個封閉被破壞了。

臨床上最常見的三件：
冠部滲漏（沒有做牙套完整包覆，或填補物久了密合度變差）、
牙齒裂開（抽過神經的牙齒失去牙髓滋養，比原本脆）、
以及根尖周圍的局部防禦下降。

三件裡有兩件，牙套都幫得上忙。
它不是療程結束後的附加選項，
本來就是這個封閉系統的一部分。

生物陶瓷負責的是根管內側最難封的那一段 ——
器械到不了的細小側枝與縫隙。
它幾乎不收縮，甚至會輕微膨脹，讓封填更密合，
並讓根管維持鹼性環境、抑制細菌滋生。

芳仁牙醫診所・雲林斗六永樂街

#顯微根管 #根管治療 #生物陶瓷 #牙套 #斗六牙醫 #雲林牙醫
```
