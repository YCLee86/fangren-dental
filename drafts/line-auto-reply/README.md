# LINE 官方帳號的自動回應訊息（2026-09-02）

**成品不放在網站上** —— 這一份是要貼進 LINE 官方帳號後台的文字，同
`drafts/door-notice/`（做完了但刻意不上站）。`drafts/` 進不了 `_site/`，
`tools/build.mjs` 也掃不到。

起因是使用者拿兩張 LINE 後台的截圖回報兩件事：

1. 病人綁定手機號碼成功之後，那句「✅ 09xxxxxxxx 綁定成功！可以啟用線上相關服務囉！」
   **被系統當成病人的訊息**，緊接著就跳出自動回應 ——「很抱歉，本帳號無法個別回覆
   用戶的訊息」。第一印象就是機器人在回絕一句系統通知。
2. 病人在官方帳號傳訊息多半是**改約診或取消**（截圖裡那位還說「我有打電話，忙線中」），
   拿到的卻是同一則冷冰冰的自動回應，**沒有告訴他接下來該怎麼辦**。

---

## 一、成因（先分清楚哪一件是壞掉、哪一件是照規則跑）

### 1-1　「綁定成功」為什麼會觸發自動回應

那句話在截圖裡出現在**對話左側、帶著病人自己的頭像** —— 也就是說，
**LINE 認定那是病人送出的訊息**，不是系統通知。自動回應對「使用者傳訊息」
一律回覆，所以它是**照規則跑，不是壞掉**。

會長這樣，最可能是綁定頁面用 LIFF 的 `sendMessages()`
**以病人的身分**把結果送進聊天室（上一則「點擊啟動完整服務 →」那張卡就是入口）。

### 1-2　⚠⚠ 這一則**擋不掉**，關鍵字回應救不了

LINE 的**關鍵字回應是「完全一致」比對** —— 好友送出的訊息要和設定的關鍵字
一字不差才會觸發。而那句話裡的**手機號碼每個人都不一樣**，
所以不可能寫出一個對得上的關鍵字，也就無法用「關鍵字回應」把它換掉或排除。

> 出處：LINE Biz-Solutions 官方教學與多家代理商的說明（見本檔最後）。
> ⚠ 這一條沒有在後台實測過，**照做之前先在後台用測試帳號試一次**。

**結論：那一則自動回應一定會跳出來，所以文案本身必須在「剛綁定完」的情境下
也讀得通。** 現行第一句「很抱歉，本帳號無法個別回覆用戶的訊息」正好是最糟的
—— 它像在回絕一句系統通知。新版第一句改成自我介紹，同一則文字在
「病人真的傳訊息」與「剛綁定完」兩種情境下都成立。

### 1-3　三條路（第 b 條是我們現在就能做的）

| | 做法 | 誰能做 |
| --- | --- | --- |
| a | 找綁定服務的**廠商**改：綁定完成改由官方帳號推播，或只在網頁上顯示，不要以病人的身分送訊息 | 使用者去問廠商（根本解） |
| b | **換文案**，讓那一則在剛綁定完也讀得通 | 這一份就是（現在就能上） |
| c | 看診時間內改用**手動聊天**，自動回應只在休診時間跑 | 要人力，診所決定 |

## 三、為什麼這樣改（逐句對照現行版本）

現行全文：

```
感謝您的訊息！

很抱歉，本帳號無法個別回覆用戶的訊息。
如有需要更改約診，
麻煩在診所營業時間來電 。
診所電話 055339369 謝謝。
診所有專業的諮詢人員，
如有療程需要了解，
請來電告知想要約諮詢師了解。
```

| 現行 | 問題 | 改成 |
| --- | --- | --- |
| 「感謝您的訊息！」 | 罐頭開場，而且在「綁定成功」那個情境下**根本沒有訊息可以感謝** | 「這裡是芳仁牙醫診所。」—— 先講自己是誰，兩種情境都成立 |
| 「很抱歉，本帳號無法個別回覆用戶的訊息。」 | **開場就是回絕。** COPY.md 第九之十七節 B：一句話寫了不對、不寫也不對，多半是被框在負面前提裡 —— 要**換框**不是換字 | 把能走的路放前面（電話），限制放後面當**理由**，並補上受益者：「免得你在這裡等」 |
| 「麻煩在診所營業時間來電」 | **沒說營業時間是什麼** —— 他要現在做決定，卻要自己再去查一次 | 直接把看診時間印出來 |
| 「診所電話 055339369」 | 和站上的寫法不一致 | `05-5339369`（2026-08-27 全站定案） |
| 「診所有專業的諮詢人員」 | **行銷腔**（COPY.md 第六節那六輪否決：「專業團隊」「歡迎諮詢」一律不用） | 拿掉形容詞，只講他要做的動作：「來電時說要約諮詢」 |
| 「請來電告知想要約諮詢師了解」 | 語法繞，而且「了解」重複兩次 | 併進第一段的「或想先了解療程」 |
| （沒有） | 病人的實際處境是**打了電話忙線**（截圖），現行文字對這件事一個字都沒有 | 補一句忙線怎麼辦 |
| （沒有） | 錯過一次曝光（TEAM.md 第六節：每一個對外接觸點都是芳仁露一次面） | 補上 `https://fangren.net` |

### 有意沒有寫的

- **不寫「我們會盡快回覆」** —— 沒有人看訊息就是承諾一件做不到的事。
- **不寫「歡迎諮詢」「專業團隊」「一定幫你處理好」** —— 行銷腔與空白支票，
  COPY.md 第三節紅線與 TEAM.md 品牌顧問紅線。
- **不寫「問到懂」「不做也沒關係」** —— 第三節那條紅線（診所給的是燈，不是答案）。
- **不寫金額、不寫療程要幾次** —— 沒問到的診所事實一律不寫。

## 四、還要問使用者的（問到才寫得下去）

1. ⚠⚠ **那個「綁定」是哪一套系統、哪一家廠商？綁定之後病人可以做什麼？**
   （線上預約？線上改約？看診進度？）—— 如果線上就能改約，這一則文案**不該只叫他打電話**，
   要先把他導去線上。這一題不確定之前，上面的稿子都只寫電話。
2. **LINE 的訊息真的完全沒有人看嗎？** 還是櫃檯偶爾會看？
   —— 決定能不能寫成「看得到，但沒辦法一則一則回」（比現在的說法暖，而且更接近事實）。
3. **電話忙線時，診所希望病人怎麼做？** 會不會回撥？
   —— 現在寫的是「隔幾分鐘再撥」，那是最保守、不承諾的寫法。
4. **看診時間內要不要改成手動聊天**（由櫃檯直接回）？自動回應只在休診時間跑。
5. **LINE 上「營業時間」欄位現在填的是哪一組？** CLAUDE.md 第十節記著三組不一致
   （網站／門口磁鐵板＝LINE 門診時間／LINE 營業時間），這一輪順便可以收斂成一組。

## 七、提案頁：在 LINE 裡面長什麼樣（2026-09-02 加）

使用者：「你們目前給我看的只有文字，我想要看到就是在 LINE 裡面的樣子，
然後要有一些顏色配置或是圖案或是照片。」

→ **<https://fangren.net/preview/line-reply/>**（三道 noindex 都在）

模擬的是**病人手機上的畫面**（官方帳號在左、他自己的訊息在右）——
⚠ 截圖裡那個「自動回應訊息」小標籤**只有管理者看得到**，病人不會看到。

兩把尺：

| 情境 | 版本 |
| --- | --- |
| 剛綁定完／要改約診／剛加好友 | 現況／純文字／純文字・完整／文字＋照片／圖文訊息・兩格／圖文訊息・四格 |

### ⚠⚠ 量出來最要緊的一件：**文字太長，一則就吃掉大半個畫面**

390×844 實測（面板會現場再量一次你自己的手機）：

| 版本 | 行數 | 泡泡高 | 佔一屏 |
| --- | ---: | ---: | ---: |
| 現況 | 9 | 239px | **28%** |
| 純文字（精簡） | 13 | 417px | **49%** |
| 純文字・完整 | 20 | 551px | **65%** ← 要捲才看得完 |
| 圖文訊息・兩格 | 8 | 239px | **28%**（＋一張 223px 的圖） |
| 圖文訊息・四格 | 8 | 261px | **31%**（＋一張 223px 的圖） |

**所以第二節那份「完整版」不建議直接上** —— 它每一句都對，但一則塞不下。
看診時間那五行搬到圖上之後，文字就回到八行。

### 圖文訊息的兩張候選（真的產出檔）

`preview/line-reply/rich-2.png`、`rich-4.png`，各 1040×1040，
產生器 `drafts/line-auto-reply/rich.mjs`（`node drafts/line-auto-reply/rich.mjs`）。

- **兩格**：上＝夜景照片＋帶子寫「芳仁牙醫診所／雲林斗六・永樂街」（點了開網站），
  下＝`05-5339369`（點了直接撥）。**一張圖只做一件事**，最不會誤按。
- **四格**：照片｜撥打電話｜看診時間（早午晚三行）｜診所位置。資訊最全，
  但每一格在聊天室裡只有約 110px 見方。

做法上照著站上既有的規矩：

- **帶子脫離照片、接在下面**（og-home 2026-08-22 定案的做法）——
  第一版把名字壓在照片上，字落在清水模牆與亮著的騎樓上，對比一路在變。
- **帶子上緣用 smoothstep 淡進來**（第九節第 10 條：線性漸層的起點是一條可見的線）。
- **看診時間與電話從 `index.html` 讀回來**，不在產生器裡抄第二份；讀不到就 throw。
- **顏色全部回 PALETTE.md 拿**：紙 `#e2e5e6`、卡 `#f4f4f5`、字 `#2a2c27`／`#5c5f57`、
  綠 `#3f654a`（一般牙科的套色）／`#2c5238`（白底上的字階）。**一顆都沒有新增。**
- **字型是真的 Noto Sans TC** —— 容器裡只有文泉驛，所以從 Google Fonts 取回需要的
  分段再子集化，存在 `fonts/`（30 個檔、共 68KB，做法同 `tools/og-plate.mjs`）。
- Chromium 挑 **headless_shell**，出圖後讀 PNG 檔頭驗尺寸（第九節第 18 條）。

⚠⚠ **兩格版切成上下各半、四格版切成四等分，是刻意的** ——
LINE 的圖文訊息版型是**固定的格子**，自己挑一個 60/40 的分法，
可以點的範圍就會和畫面上的分界對不起來。**後台實際有哪幾種版型要確認過再定案。**

### 這一輪還沒做的

- **圖上的字在後台上傳前要再看一次**：LINE 會把 1040 的圖縮到約 223px 顯示，

## 八、⚠ 2026-09-02 第二輪定案候選（現行版本，取代第二節）

使用者選了**四格圖**，並提了三件：① 文字太多，歡迎那一則要短、要講「這個 LINE 有什麼功能」；
② 不需要寫「無法一則一則回覆」那種說明；③ 病人**打字之後**那一則要另外做，
而且不能只說「這裡沒有人」，要**把功能一起秀出來**。

### 8-1　先分清楚：後台是兩個設定，而且 LINE 分不出「綁定完」和「打字問事情」

| | 什麼時候送 | 可不可以用 `{好友的顯示名稱}` |
| --- | --- | --- |
| **招呼訊息** | 只在「加好友」的當下送一次 | ✅ 可以 |
| **自動回應** | 病人送出**任何**訊息都會回 —— 包含那句「綁定成功」 | ❌ 不行 |

**所以自動回應只有一份，它必須同時在「剛綁定完」與「打字要改約」兩種情境下讀得通。**
（想讓綁定完那一刻長得不一樣，只有一條路：請廠商別以病人的身分送那句話 —— 見 1-3。）

### 8-2　招呼訊息（加好友）＝ 四格圖 ＋ 這段文字

```
{好友的顯示名稱}你好，這裡是芳仁牙醫診所。
斗六永樂街上，1983 年開到現在。
```

### 8-4　三件寫法上的判斷

- ⚠⚠ **電話號碼要自己一行。** 第一版寫成「直接撥 05-5339369 最快，」，
  在 390 寬的手機上被折成 `05-` ／ `5339369` 兩行 —— **折了就不再是一個可以點的電話**。
  （LINE 會自動把電話變成連結，前提是它沒有被折斷。）
- **「沒有專人看訊息」留著，但只留一句**，而且後面立刻接能走的路。
  使用者要的是「不要只說這裡沒有人」，不是「不要說」—— 不說的話病人會一直等。
- **功能寫成他要做的事**，不是我們有什麼：「改約診、取消 —— 打電話最快」，
  不是「本帳號提供預約異動服務」。

### 8-5　四格圖改了一格

左上原本是照片＋「芳仁牙醫診所／雲林斗六・永樂街」，**第二行換成「診所網站」** ——
使用者說四格「不是一個完整的回應說這有什麼功能」，問題就在那一格：
其他三格都寫著點下去會怎樣（撥打電話／看診時間／診所位置），只有它沒有。
地名沒有因此消失，右下角那一格就是「永樂街 70 號」。
