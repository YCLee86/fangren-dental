## ⚠⚠ 三件不可以做的

1. **不可以描摹、不可以進 `assets/`、不可以上站。** 九張都帶著素材站的浮水印。

2. **不可以照抄 ⑬ 頭上那些手寫假名**（撞第七節第 4 條 `NO WRITING` 那條硬紅線）。
3. **不可以照抄 ⑱ 的臉**（線最粗、而且有眼白，會把我們推回第十六節治過的「畫得太準」）。

## 量到的數字

`node drafts/expression-marks/measure.mjs`（Chromium canvas，零 npm 依賴）
量的是 ⑮；⑰ 那一組的視窗在 `measure.mjs` 的註解裡。兩組合起來：

標記高度對頭高 **18%~49%**（四角星最小 18/25%，三個漸大的圓最大 28/49%）。
標記的墨量對頭的墨量 **3.5%~15.6%**。
⚠ 兩組數字有差，成因是量測視窗切到的髮量不同 —— **拿它當上限，不要當目標值。**
