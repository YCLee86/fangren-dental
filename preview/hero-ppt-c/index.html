C 版：詩句靠左，和診所名共用一條左緣

PPT 上有三條左緣（Logo、診所名、置中的詩），在 13 吋投影片上鬆得剛好，縮到 390px 會顯得散。這裡讓診所名、副標、三行詩共用同一條左緣，由上而下一路變輕：粗體 → 一般 → 更淡，讀起來是一段自然收尾的文字。選單留在右上角，和 PPT 一樣。

照片尺寸怎麼定的

高度是 clamp(268px, 40svh, 345px)，佔畫面高度 40%——前次聊天定下的 1/3～2/5 區間的**上緣**。這一案是三案裡唯一把頁首和三行詩都壓在照片上的，而照片能用的暗部只佔它高度的四分之一，非得取到 2/5 才裝得下兩者。

為了擠進去，這一版的行距收到 1.55（A 版 1.7、PPT 200%），頁首和詩之間幾乎沒有留白，而且整層疊字（連頁首一起）都改用 cqh、綁在照片高度上——不然換一支矮手機，頁首沒縮、暗部縮了，詩就被推出安全區。

三種螢幕實測對比：375×667 是 5.16:1、390×844 是 4.57:1、430×932 是 5.16:1。4.57 是三案裡最緊的數字，只比 AA 門檻高一點點。若之後照片換掉、裁切位置動了、或詩的字數改了，這一版一定要重新量。

一樣只裁左右、不裁上下，不加漸層、不加遮罩。
