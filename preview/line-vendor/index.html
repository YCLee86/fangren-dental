③ 對方講的每一句，真不真「做不到」一律先改寫成「誰做不到」

他說的判斷實際上是什麼
後台送不出 Flex Message 對 LINE 平台完全送得出，是那個編輯介面的型別下拉沒有 Flex —— 換一個人送就好，而他們自己一直在送。
綁定完成訊息為公版，故無法調整 對，而且不必改 那句話是病人那一側送出的。我們從來沒有要改它 —— 在它後面再送一則就好。
背景只能全白或其他顏色，無法放圖示 對，但答的是另一個問題 Flex 的 box 真的沒有背景圖。但浮水印不是背景，是 image ＋ absolute；而「卡片裡放得了圖」他們自己那張預約成功卡頂端就有一顆標誌。
官方 LINE 無法針對抓關鍵詞跳不同訊息，已釘死 只有一半對 後台的自動回應確實分不開「這一句」（關鍵字是完全一致比對，而那句話含著每個人不同的號碼）。但後台本來就設得了好幾則各自一組關鍵字，而且這一則根本不必由後台回 —— 那句話是他們的系統送出來的，他們在那一刻就知道綁定好了，不必比對任何字串。
綁定成功訊息沒辦法拿掉，因為 a 需通知病患 有反例 玉山那一則「您已成功申請個人化通知服務」是商家自己送的，而且一個號碼都沒有 —— 通知這件事不需要那句話。
…因為 b 櫃檯可以馬上透過手機號碼查看病患資料 新資訊，要留著 這件事我們以前不知道：那則訊息同時是櫃檯在聊天室裡查號碼的入口。所以「不發送」會拿掉櫃檯的一個功能 —— 問題徹底收斂到這一句。

④ 別家帳號那幾張的證據力拿出去之前先問：它證明的是哪一句話

新竹品御牙醫⭐ 主力

同一個廠商的另一間診所。按約診查詢 → 一模一樣那張藍色公版卡 → 病人那一側送出「✅ 09xxxxxxxx 綁定成功！」→ 後面什麼都沒有。

同一套系統、同一句話，在那一間診所沒有觸發任何通用回覆。而它的頁首寫著「此官方帳號正在自動回覆訊息」＝ 有開。

玉山銀行補刀

綁定成功那一則是商家自己送的（左邊灰泡泡），而且一個號碼都沒有。另外打「玉山」「早安」「午安」回三則不同。

廠商的理由 a 有反例了。⚠ 而「午安」回了「台幣匯款說明」＝ 關鍵字分流會出錯，出錯的樣子就是答非所問。

潔客幫背景

8:10 綁定完成回「謝謝你完成好友綁定＋200 元折價券」，9:34 打「早安」回「感謝您來訊…客戶服務時間…」。

綁定那一刻回專屬的、其他時候回通用的，同一個帳號兩則並存而且真的在跑 ＝ 使用者要的形狀。⚠ 但那一則有可能是後台的加入好友歡迎訊息，時間戳分不出來。

BREAD, ESPRESSO &背景

12:00 按綁定 → 12:02 回「恭喜您已接受邀請成為麵包學徒」，中間病人那一側一句話都沒有；而打「早安／午安／晚安」三則都沒有回應。

它根本沒開自動回應，所以那一則必定是系統送的。⚠ 是未認證帳號，對方可能拿這一點說嘴。

中國信託背景

綁定完成回一張帶四顆按鈕的 Flex 圖卡，頭圖上寫著「綁定完成！」。打「早安／午安／晚安／等好久」四句四則不同。

綁定完成那一則可以是 Flex 圖卡 ＝ 和我們那張同一類。⚠ 四句全是固定字，反駁不了「含號碼的那一句抓不到」。

台北富邦背景

「恭喜成為我們的綁定好友」＋下載行動銀行的連結卡；打三句都回同一張「數位客服邦尼」。

回一則通用的 fallback 是常態、不丟臉 —— 我們那一則的存在是對的。

國泰世華背景

同一分鐘內：打別的字回「我無法理解該字詞意思」、打「綁定」回帶名字的專屬卡。

專屬的一則和通用的那一則可以在同一個帳號裡並存。⚠ 「綁定」是固定字，仍然反駁不了那一句。

⚠⚠ 七張一起丟會被挑最弱的那一張回。主力擺品御、玉山補刀，其餘五張只在被問「有哪些例子」時才拿出來。拿別人家的畫面當證據之前，先問它證明的是哪一句話。
