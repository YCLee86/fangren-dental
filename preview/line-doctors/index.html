現況（對照）

逐項

  1. 1　插畫太大

    問題
    插畫佔卡片高度約 62%，名字與資歷被擠到最下面。
    事件
    網站已經用 76px 的小圓頭像解決過同一件事。
    解決方案
    拿掉大圖；頭像 76px 放左上，名字與專科標籤放右邊。尺寸定案 kilo（260px，9/24 實機測過 mega／giga／micro／kilo 四種），卡高 340px，資料從頂端就開始。

  2. 2　插畫不是醫師本人

    問題
    男女各一張通用插畫，九位共用。
    事件
    網站上八位已經有本人的形象照（林晏妤、許馨文 9/24 補上）。
    解決方案
    直接用網站那八張照片（fangren.net 上的 JPEG），專科標籤用網站同一顆科別色。

  3. 3　廖立揚醫師沒有照片

    問題
    廖立揚醫師沒有照片。
    事件
    網站上這一張是純文字卡（照片 9/23 依要求移除）。
    解決方案
    同網站，不補插畫、不放佔位圖。之後照片上了網站，重跑一次產生器就會跟上。

  4. 4　用 ChatGPT 送到 LINE 測試

    問題
    要先在真的 LINE 上看過，模擬圖不等於 LINE 的實際畫面。
    事件
    9/24 使用者指定：用已經連動 LINE 官方帳號的 ChatGPT 送測試訊息。卡片是 Flex Message JSON（16.2 KB，上限 50 KB）。
    解決方案
    上面那顆按鈕複製「指示＋卡片」整段貼給 ChatGPT；指示限定只傳給自己。待使用者測試回報。
