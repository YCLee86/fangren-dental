N3　藍灰調　#e2e5e6　（木線已拿掉）＋ 固定頁首 ＋ 一科一色的實心藥丸

2026-08-07 定案：一科一色 ＋ 實心反白藥丸，左邊條收掉。只動醫師介紹與診所資訊兩節，文章區一個值都沒碰。 切換條已經拿掉了，這頁現在就是定案的樣子。卡底 #f4f4f5 一動不動 —— 紙對卡本來就只差 1.152:1，卡一往紙靠，「灰是比出來的」那條就毀了。

六個科別色，全部是 PALETTE.md 裡就有的值（官方色票原值，或診所實物的實測色），沒有一個是憑感覺調的。 後面的數字是純白字疊在該色上的實測對比，藥丸 11.5px，AA 要 4.5:1：
一般＋牙周植牙　#4f6361　診療椅實測　　　　H=174　6.38:1
顯微根管　　　　#5D6D55　色票・苔綠（Logo）　H=100　5.55:1
齒顎矯正　　　　#3C596B　色票・藍灰（候診沙發）H=203　7.41:1
口腔外科　　　　#7D5A58　色票・Deep Taupe（單椅布料）H=3　6.04:1
贋復假牙　　　　#252d4a　茶室深藍磁磚實測　　H=227　13.53:1
兒童牙科　　　　#8d5e3a　圓凳與木件實測　　　H=28　　5.53:1

三個用實測色而不是色票原值，各有理由： #4f6361 是你指定的，它在 PALETTE 第一節、對深綠松 ΔH=1，本來就是同一個色的實物版。 兒牙從磚紅換到暖色這一支之後，官方色票的焦糖褐 #9B735E 太淺、白字只有 4.19:1 撐不住， 所以取同一族的實物實測值（圓凳與木件，對焦糖褐 ΔH=5），夠深。 贋復要跟口外分開，就拿整個色盤裡最深的那一個（茶室深藍磁磚）—— 全口重建配最重的色。

為什麼藥丸一定要反白。藥丸字要維持色票原值，底就壓不下去：深綠松、藍灰吃得下 22%， Deep Taupe 18%，苔綠 15%，磚紅只能到 10%（12% 就掉到 4.48，過不了 AA）。 反白反而最寬鬆，而且六個色的視覺重量終於一致 —— 淡底那組深綠松 8.31 對磚紅 4.75，差了快一倍。

兩件要你決定的事： ① 贋復 #252d4a 與矯正 #3C596B 是兩個藍（H 227 對 203），靠深淺分開。 要換的話，備案是枝葉亮處 #447c56（H=139，白字 4.93:1），但那樣頁上會有三個綠。 ② 「週六、週日休診」那一行還是磚紅 #AF4C52。你說紅在品牌裡暗示性太強 —— 這行是唯一還留著紅的地方，要一起拿掉的話講一聲，改成次要墨色就好。

2026-08-07：四個小節的副標全部拿掉了。 「依最後更新時間排序，最新的在前」是在解釋機器怎麼排的，讀者沒問過 —— COPY.md 第三節早就用同一個理由否決過「一篇一篇寫在這裡」（功能導向太強、主詞是文章不是人）。 「看診團隊與各自的專科」是「醫師介紹」的同義重述，而且專科現在寫在藥丸上了，那行等於在描述眼睛已經看到的東西。 「雲林縣斗六市・在地經營超過四十年」本身有內容，但同一頁已經講了三次： 頁首副標「雲林斗六・永樂街」、窄帶的 1983／9／6、頁尾一字不差的同一句 —— 那是第四次。 頁尾那句留著，那裡是它該在的地方。標題底下的 .2rem 也一起收掉了，不然會留一段空的。

2026-08-07：專長／資歷／學歷 的標籤，底色定案為紙色底。 形狀比照 fangren.net 現在的 .doctor-facts dt，顏色改灰階 —— 藥丸已經是六個實心的科別色了，標籤再上色會太花。 底 #e2e5e6（--paper）＋ 字 #5c5f57（--ink-soft），實測 5.14:1，字級 11.8px 過 AA。 字重從正式站的 700 收到 500 —— 灰的 700 看起來比 teal 的 700 重一階。

標籤往下拉長是 bug，已經修掉了。原因是 grid 項目預設 align-self: stretch： 格線列有多高、底就被拉多高，所以「資歷」那種三行的內容會把標籤從第一行一路拉到第三行底部。 加上 align-self: start 之後就只包住字了。 （旁邊那個 justify-self: start 是另一件事，少了它底會被 3.2em 的欄寬撐滿，變成長短不一的灰帶。）

圓角：比例對齊，不是同一個數字。四案裡選了 4「各自往中間靠」，但一開始四個標記全寫 8px 就不對 —— 治療項目的 chip 明顯偏方。量出來原因很清楚：圓角要看的是半徑與框高的比例，不是絕對值。 醫師藥丸高 20.86px 配 8px，比例 0.384；chip 的框大得多（高 31.00px，字 13.12px、上下內距各 4px，藥丸只有 0.8px）， 同樣 8px 落上去只有 0.258，所以看起來是方的。
改成各自取 0.384 × 自己的框高：治療項目 chip 12px、文章標籤 8.5px、診所資訊標籤 9px、醫師藥丸維持 8px。 實測比例 0.387／0.381／0.380／0.384，四個一致。 （另一條路是把 chip 的內距縮小讓框變矮，但那會動到觸控面積，先不動。） 專長標籤維持 6px／比例 0.271 —— 它本來就要比標記方一階，那正是選 4 的意思。

2026-08-07：科別色推廣到治療項目與文章標籤，兩個填色版本在頁上可以切（切換條在「治療項目」標題底下，三節一起換）。 對應關係寫在 data-spec 上，跟醫師卡共用同一組色 —— 所以「兒童牙科」在治療項目、文章標籤、醫師藥丸三個地方一定是同一個色，不會各講各的。 治療項目：一般＝#4f6361・牙周＝#4f6361・兒牙＝#8d5e3a・矯正＝#3C596B・植牙假牙＝#252d4a。 文章六篇：兒童牙科×2＝#8d5e3a・定期檢查＝#4f6361・缺牙重建＝#252d4a・牙周照護＝#4f6361・日常保健＝#4f6361。

填色定案：線性為主，只有醫師藥丸是實心的。切換條已經拿掉，這頁就是定案的樣子。
治療項目、文章標籤、診所資訊：線條與文字套色，底不套色。色票字疊在卡色 #f4f4f5 上 5.03~12.31:1，最低是兒牙 #8d5e3a。
醫師藥丸：套底色、字反白。白字對六個科別色 5.53~13.52:1。

2026-08-07 新增：治療項目可以點，會同時篩選文章與醫師。 點「兒童牙科」就只留下兒牙的文章與兒牙專科的醫師，被按下去的那顆換成實心（跟醫師藥丸同一種份量 —— 它代表「你正在看這一科」）。文章標籤與醫師藥丸的樣子完全不變，只有數量變少。再點同一顆就回到全部。
底下會出現一行狀態：「兒童牙科：2 篇文章、2 位醫師。」—— 「文章」「醫師」是連結，點下去跳到對應的小節（數量是 0 的時候不給連結，跳過去只會看到空的）。 齒顎矯正目前一篇文章都沒有，那一科會顯示「這一科目前還沒有文章」，不會變成一片空白。

文章卡仍然是靜態 HTML，一張都沒有由 JS 產生。（CLAUDE.md 第一節第 1 條） 這裡只是把不符合的卡加一個 class 藏起來，原始碼裡六張卡永遠都在 —— 搜尋引擎與無 JS 的環境看到的是完整清單。 沒有 JS 的時候，chips 就是五顆按不動的按鈕，底下什麼都不會被藏，不會壞。 對應關係讀的是 HTML 上的 data-spec，跟配色共用同一個屬性，所以顏色與篩選永遠不可能對不起來。

為什麼只有醫師藥丸填滿。同樣是「科別」兩個字，在瀏覽者心裡不是同一個層級： 治療項目與文章上的是分類（站上有哪些科、這篇屬於哪一科），醫師卡上的那顆是在認人（這位醫師是哪一科的）。 認人的份量比分類重，所以只有它填滿。這不是前面說的那種「一半實心一半線性」的衝突 —— 差別對應的是真實的層級差，不是隨機的。實心那顆的框也給同色邊框（不是透明），尺寸才跟線性那三處完全一致。

一個技術細節：治療項目的 chips 底維持 var(--card)，不是留透明。 它們躺在紙 #e2e5e6 上，底若透明，兒牙 #8d5e3a 對紙只有 4.37:1、掉出 AA； 墊那層卡色才是 5.03。所謂「底不套色」指的是底不吃科別色，不是底完全不上色。

電話是唯一填滿的那一塊。整節裡只有它需要視覺停下來，所以只有它拿到一塊實心的底。 塊是放在白卡裡面的：底 #dbe0e0（深綠松 12% 混進卡色）對卡 #f4f4f5 差 1.21:1，在卡上讀得出來，字疊上去 7.09:1； 同一塊要是拿去當卡底，它會跟紙 #e2e5e6 差不多，卡就整個消失了 —— 這也是為什麼九張醫師卡的底都沒有動。

2026-08-06 併入：捲動時固定頁首。固定的是 HERO 原本那一排本人，不是另做一條；捲動時收合（整組等比縮 0.9、副標保留），底下是一層毛玻璃 —— 在照片上通透看得到建築，捲進內文之後變成不透明的 #32353c。漸變全部在窄帶上走完，灰底出現時畫面不會再有任何變化。捲動位置 0 與定案的 HERO 完全相同。

木線沒了。暗夜窄帶直接接到內文底，中間什麼都沒有。你說的沒錯——拿地板當識別色本來就站不住，那條線的存在感又比它承擔的意義大。識別色之後另外選。

底色：紙 #e2e5e6　卡 #f4f4f5　線 #cdd0d2。H=203・L=89.4%・R−B −4（三案裡唯一有色偏的）。你要 G1 那種涼，但不要紫。這一版把色偏換成官方色票的藍灰 #3C596B（H=203）—— 候診沙發、長椅、夜空都在這條軸上，是診所裡唯一天然的冷色，跟紫沒有關係。
