三則裡的第三則。招呼卡、綁定完成、提醒卡都定稿了，剩這一則。
底下四把尺。上面那一塊先回答你問的那兩題。

你問的那兩題，LINE 後台的答案

一、文字和圖可以交替，不是一則文字只能配一張圖
後台一則自動回應底下按「＋新增」可以再加一個對話框， 每一個對話框各自選類型（文字／圖片／貼圖／影片／圖文訊息／優惠券／問卷）。 所以「文字 → 圖 → 文字」做得出來，切到右邊那兩格就是。
⚠ 對話框的上限查到兩種說法（3 個或 5 個）—— 要在後台按「＋新增」按到不能再加為止，那個數字才算數。
二、「做幾個版本」在 LINE 上有三種，只有兩種是準的
・關鍵字分流：打「改約」回 A、打「時間」回 B。準，一組關鍵字最多 51 個詞。
・時段分流：開診時間一則、休診一則。準（設的是星期＋時間）。
・好幾則都不設關鍵字：LINE 隨機挑一則送。 病人問同一件事會拿到不一樣的答案，這一種不要做。
⚠ 隨機那一條是二手資料，要在後台自己確認一次。
三、⚠ 這裡的「圖卡」目前不是綁定完成那種圖卡
綁定完成那種卡片裡有真文字、有按鈕的是 Flex Message， 後台選單裡沒有這個選項，要廠商用 API 送 —— 那正是還在等廠商回答的那一題。
自動回應這裡現在能放的圖是圖文訊息：一張 1040 的圖切成格子， 每一格設一個動作（開網址／撥號／傳一句話）。字是烘在圖裡的， LINE 會把它縮到 223px 顯示（390 寬實測）。
