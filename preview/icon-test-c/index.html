圖示對照測試 C・整片套色

這一頁測的是整片套色：底是品牌綠、標誌是白色 —— 和新思惟國際那顆（整片紅底 ＋ 白字標）同一個結構。宣告環境和測試頁 A、B 一樣乾淨。

會做這一版，是因為量出來深底／套色那一類確實比較銳利（只取圖示中央、避開 iOS 自己畫的遮罩邊，用「一個像素跨掉多少反差」計算）：

A・白底＋深綠（我們）　　90.9%
B・黑底＋米色（我們）　　95.2%
新思惟・整片套色＋白字　95.9%

  1. 用 Safari 的「分享 → 加入主畫面」把這一頁加上去
  2. 和首頁那顆放在一起比較

這一顆和 B 差不多銳利 → 那就確定是「底深、標誌淺」這個結構的功勞，和配色細節無關。整片套色比純黑更像品牌的樣子，可以考慮定案這一版。

比 B 差 → 那 B 的黑底才是關鍵，得再想。
