固定頁首・收合字級修正 ＋ 玻璃邊三檔

你講的那件事可以用算的，不必憑感覺調。「兩邊看起來同一個顏色」是一條等式：合成色 C = a·T + (1−a)·B（T 是玻璃染色、B 是底下的畫面）。暗區用很低的遮罩求出 C，再反推淺區要用什麼染色才會落在同一個 C 上。

先量兩個底（把 45.8px 高的條子底下的畫面，在整段捲動範圍內取樣）：

暗區（照片＋窄帶）平均 #34373e　L* 23.0（範圍 L* 10.1〜32.6）
淺區（內文）　　平均 #dde3e1　L* 89.8

遮罩 .06、模糊 6px 都定案了，這一輪處理你講的另外兩件事。

字級那兩個問題其實是同一個根因。原本收合只縮了標題（縮到 clamp(12.5px, 3.3cqw, 15.5px)）、副標完全沒動，於是：

・標題與副標的字級比從 1.457 掉到 1.25——標題看起來就跟副標差不多小。
・「芳仁牙醫診所」6 字 × 12.87px = 77.2px，比「雲林斗六・永樂街」8 字 × 10.2px = 81.6px 還窄。區塊寬度於是改由副標決定，而副標是 text-align-last: justify 會撐滿整個寬度 —— 標題比較窄，右緣就對不齊了。

改法：整組等比縮 0.9，不是只縮標題。把六個數字（min／cqw／max）全部乘 0.9 之後，字級比在任何寬度下都與休止狀態完全相同（390px 是 1.457、375px 是 1.429，兩種狀態一致），標題也永遠比副標寬，右緣自然對齊。圖標也一起照 0.9 縮。

下緣那條線做成三檔，含完全不要：

無線　　完全拿掉
0.5px　@.10 —— 半個 CSS 像素，DPR 3 的手機上是 1.5 個裝置像素
1px 淡　@.08 —— 保持 1px 但透明度從原本的 .14 降到 .08

這條線唯一的工作是說「玻璃到這裡為止」—— 遮罩只有 .06，條子跟底下的照片幾乎沒有明度差。但它太明顯就變成一條裝飾線，你會注意到它不是沒有道理。拿掉之後玻璃的邊界只剩模糊在講，捲到內文區時因為底色差夠大，其實看不出差別；差在照片上那一段。

先前定下來的都沒動：遮罩 .06（合成 #32353c L* 22.2、淺區染色 #1f222a@.90、兩區同色）、模糊 6px、副標維持 HERO 的 .65、捲動位置 0 完全沒有玻璃。條子的顏色會跟著照片擺盪（約 L* 10〜31），那是選 .06 換來的，也是它看起來像玻璃的原因。

還有一個附帶的好處：副標退回 .65 了。第三輪因為玻璃壓在亮內容上把條底推到 #5d6062，副標 .65 只剩 3.68，當時被迫提到 .80。自適應之後合成色是 L* 18〜21，.65 實測 6.44〜6.85 —— 那條提亮規則整個拿掉了，副標與 HERO 完全同值。自適應不只是好看，它把那個妥協消掉了。

過渡不是硬切。條子高 45.8px，窄帶穿過它要 45.8px 的捲動距離，這段期間條下同時有暗有亮，硬切一定會露破綻。所以用捲動進度在兩組 rgba 之間線性內插——底下的畫面與染色同步變化，合成色在整段過渡中幾乎不動。

字色全部是 HERO 的原值：品牌名 .95、副標 .65、nav .88。捲動位置 0 完全沒有玻璃。
