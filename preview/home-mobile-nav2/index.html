固定頁首・第二輪　A 紙色／B 暗夜／C 收合

這一輪沒有第二條列。固定在頂端的就是 HERO 原本那一排 .site-header 本人 —— 你在最上面看到的那一排，捲下去之後留在原地的是同一個元素，不是另外冒出來的東西。

搬動它要處理三件事，都處理掉了：

・它原本在 .hero-copy 裡，而那是絕對定位在有 overflow: hidden 的 .hero-photo 之內 —— sticky 在那裡面只會黏到 HERO 結束就跑掉。所以搬成 .phone 的直接子元素。
・搬出來之後容器查詢單位會改變意義（原本是 cqh，新容器只有 cqw）。兩者有精確換算：照片高 = 74.72cqw，所以 1cqh = 0.7472cqw。全部照這個換完，是等式不是近似。
・詩的位置不能跑掉。原本詩的位置 = 5cqh ＋ 頁首高 ＋ 7cqh，頁首搬走會讓詩往上跳。所以原地補了一個等高的佔位，高度用同一組 clamp 公式算，任何寬度下都等高。

三案差在「落到淺色內容上之後怎麼辦」——這是非做不可的，白字在紙色底上看不見：

A 紙色換裝　底變成卡片白、字變墨色、連結變深綠松。照 PALETTE.md 兩套色的邏輯：捲進內文就換內文的衣服。

B 暗夜換裝　底變成窄帶的 #282b31，字維持白。夜跟著一起走。

C 收合　毛玻璃底，副標「雲林斗六・永樂街」淡出收起、品牌名縮小，整條變矮。強調的是佔的空間變小，不是換顏色。

我的建議還是 A。理由跟上一輪一樣：這頁滑動時視線一直在淺色上，B 和 C 會讓一塊深色常駐在頂端，小螢幕上等於永久扣掉一條。而且 PALETTE.md 第六節第 4 條寫的是「暗夜只留在 HERO，不延伸到內文區」—— B 和 C 都把夜帶進了室內。
C 的收合在功能上最省空間，如果你覺得固定條佔位太多，那就選 C。

已實測比對：捲動位置 0 時，這一頁的頁首與詩句座標與定案的 home-mobile-n3 完全相同（375／390／430 三個寬度都比對過）。也就是說「沒捲動的時候，這一頁跟現在長得一模一樣」。

切到「不固定」時，那一排會用 absolute，行為跟現在完全一樣會捲走。
